## Design

Spec `## Proposed Fix` is implemented as written. Key decisions fixed by this plan:

- **Launch module** `extensions/drm-copilot/src/worktree-session-launch.ts` (pure; imports only types from the two builder modules) exports `MAX_ENCODED_COMMAND_LENGTH` (30000), `encodePowerShellCommand(script)` (base64 of UTF-16LE through `Buffer`), `buildEncodedShellArgs(script)` (returns `-NoLogo`, `-NoExit`, `-EncodedCommand`, encoded; throws an `Error` whose message names the encoded length and the limit when the encoded length exceeds 30000), `buildClaudeSessionScript(commands)`, `buildCodexSessionScript(commands)`, `buildClaudeSessionShellArgs(commands)`, and `buildCodexSessionShellArgs(commands)`.
- **Script shape** (LF-joined): `& {` ; `$setupSucceeded = $false` ; `try {` ; per emitted step a banner `Write-Host '==> <label>'` then the step command ; after the `git` step `if ($LASTEXITCODE -ne 0) { throw ('git worktree add failed with exit code ' + $LASTEXITCODE) }` and after the `poetryInstall` step `if ($LASTEXITCODE -ne 0) { throw ('poetry install failed with exit code ' + $LASTEXITCODE) }` ; `$setupSucceeded = $true` ; `} catch { Write-Host "<Session> session setup failed: $_" -ForegroundColor Red }` ; `if ($setupSucceeded) {` launch banner and agent command `}` ; `}`. `<Session>` is `Claude` or `Codex`. Banner labels: ensureParentDirectory `Creating worktree group directory`, git `Adding git worktree`, setLocation `Entering worktree`, trustCodexProject `Trusting worktree for Codex`, poetryInstall `Installing dependencies with poetry`, activate `Activating virtual environment`, preClaude `Running pre-claude script`, postCodex `Running post-codex script`, launch `Starting claude` or `Starting codex`. No `&&`, `||`, `$IsWindows`, or `$ErrorActionPreference` appears.
- **Activation probe** is the exported constant `VENV_ACTIVATE_COMMAND` in `claude-worktree-session.ts`, with the exact text in spec `#### Data flow and validation changes`; `codex-worktree-session.ts` imports it next to `quoteForPwsh`.
- **Cmdlet steps** become `New-Item -ItemType Directory -Force -Path '<group>' -ErrorAction Stop | Out-Null` and `Set-Location '<path>' -ErrorAction Stop` in both builders. The `New-Item` inside `buildCodexTrustCommand` is unchanged.
- **Handlers** compute shell args before `vscode.window.createTerminal({ name, cwd, shellPath, shellArgs, hideFromUser: true })`, then call `terminal.show()` once; no `sendText`, no timer. The log line ends with `session script delivered through -EncodedCommand` in place of the deferred-send text.
