The pre-existing root `format:check` failure on `tests/fixtures/**` JSON is excluded as in #802.

**Chosen approach (decision record):** raise the direct `@modelcontextprotocol/sdk` dependency to `"^1.31.0"` in all three manifests and add a flat top-level `"proxy-addr": "^2.0.8"` to each `overrides` block (proxy-addr is transitive through express 5.2.1, whose own range already admits 2.0.8). P0-T8 re-verifies the consumer set with `npm ls` before any edit; if any proxy-addr consumer requires a major other than 2, P1 must not start and the plan returns to the planner. `@types/vscode`, `@types/node`, and `typescript-eslint` must not change, because an `@types/vscode` bump breaks `vsce package` (the failure seen in Dependabot PR #827).
