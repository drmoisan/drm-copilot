## Measurement Definitions (fixed)

**D-COV-FRESH.** `stat -c %y artifacts/pester/powershell-coverage.xml` (last-write time) and `grep -n -F -e 'report name="Pester (' artifacts/pester/powershell-coverage.xml` (report stamp). A run "rewrote the file" when both values differ from the values recorded immediately before the run.

**D-COV-ROOT.** `grep -c -E -e '^  .counter type="LINE" missed=' artifacts/pester/powershell-coverage.xml` (expected `1`), then, as one command line:

```
grep -E -e '^  .counter type="LINE" missed=' artifacts/pester/powershell-coverage.xml | awk -F'"' '{ pct = 100 * $6 / ($6 + $4); printf "covered=%d missed=%d total=%d pct=%.2f floor85=%s\n", $6, $4, $6 + $4, pct, (sprintf("%.2f", pct) + 0 >= 85) ? "MET" : "NOT-MET" }'
```

**D-JUNIT-DIAG (diagnostic; an acceptance condition only in P1-T3).** `stat -c %y artifacts/pester/pester-junit.xml` before and after the call; when the value changed, run `awk '/<testcase /{ t = $0; sub(/.* name="/, "", t); sub(/".*/, "", t) } /<failure/ { print "FAILED: " t }' artifacts/pester/pester-junit.xml` and record its output (test names only; no `classname` and no host path).

**D-CB-READ (CmdletBinding placement).** One command line per path:

```
awk '{ sub(/\r$/, "") } /^function / { name = $2; all[name] = 1 } prev == "    [CmdletBinding()]" && $0 !~ /^    \[OutputType\(/ { bad++ } $0 == "    [CmdletBinding()]" { cb[name] = 1; n++ } { prev = $0 } END { for (f in all) if (!(f in cb)) print "NOCB " f; printf "cmdletbinding=%d misplaced=%d\n", n, bad + 0 }' <path>
```

It prints one `NOCB <function>` line for each function without a `[CmdletBinding()]` line, then `cmdletbinding=<n> misplaced=<m>` (a `[CmdletBinding()]` line not directly followed by an `[OutputType(` line counts as misplaced). The order of `NOCB` lines is not significant.

**D-LC.** `awk 'END { print NR }' <path>`.

**D-JUNIT-SUITE (local per-suite counts; the acceptance of P4-T4 only).** One command line:

```
awk '{ sub(/\r$/, "") } /<testcase / { c = $0; sub(/.* classname="/, "", c); sub(/".*/, "", c); n = split(c, p, /[\/\\]/); s = p[n]; total[s]++; if ($0 ~ / status="Passed"/ && $0 ~ /\/>$/) pass[s]++ } END { for (s in total) printf "%s tests=%d passed=%d\n", s, total[s], pass[s] + 0 }' artifacts/pester/pester-junit.xml
```

It prints one line per suite file name (the last path component of the `classname` attribute; no host path) with the number of its testcases and the number that carry `status="Passed"` and close on the same line (no `failure`, `error` or `skipped` child). The order of lines is not significant.

**Test-call rule (Phases 1 and 2).** A test task that raises records the error text and the D-JUNIT-DIAG output, corrects only edits made by its own phase (never a row name, an assertion, the construct a TEST-1 fixture places the mock in, or the CR-F4 fixture string), and repeats the call. A failing TEST-1 or CR-F4 row whose fixture is as specified is not corrected: the task records `ROW-FAILS-AS-SPECIFIED: <test name>` and stops with BLOCKED, because the remedy would change guard behaviour. A third raise of the same task stops with BLOCKED. P1-T3 is an [expect-fail] task and is exempt from this rule.
