## Overview

Epic #1018 moves the three agent ecosystems in this repository onto shared cross-tool conventions so that each tool loads every skill and instruction exactly once with default settings. GitHub Copilot in VS Code reads `.github/skills`, `.claude/skills` and `.agents/skills`; `.github/skills` is a strict subset of the other two skill folders by name (refresh research section 2.1) and causes duplicate loading. `.github/agents` (`COPILOT-AGENT-FILES`) duplicates agent definitions that Copilot in VS Code also reads from `.claude/agents`, with the name collisions listed in research section 2.1 plus `DOCS-AGENT-ROLES` (refresh research section 2.2). No repository file contains any `chat.*` collision setting (refresh research section 2.3).

This feature (child 6 of the epic) retires `.github/skills`, settles `.github/agents` according to child 1's recorded E3 result, reduces the Copilot layer to the native surfaces that have no shared equivalent, delivers or documents the Copilot collision controls according to child 1's recorded E4 result, retires the `AGENTS.md` sync writer (owner decision H3), and updates every mirror, manifest, matrix entry, contract test and process-reduction ledger record that pins a removed or changed file.
