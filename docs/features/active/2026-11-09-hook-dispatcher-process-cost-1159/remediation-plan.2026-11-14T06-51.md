## Pre-Mortem

- Review checklists: a reviewer finds an arrived `-Force` import, an unprobed changed hook, or a registration consumer from `origin/main` not re-targeted. Prevention: [P0-T4] derives all three sets mechanically against both merge bases; [P0-T5] and [P0-T6] cover F2 and F1 with new records; [P1-T13] walks all three templates.
- Coverage: an edited arrived hook could sit below 85% from `origin/main`. Prevention: [P1-T9] reads its per-file figure and adds tests in its existing test file before the loop closes; the one-line `-Force` removal adds no executable line.
- Mirror parity: an edited hook or registry could diverge from its bundle copy or miss `core.json`. Prevention: every editing task copies its bundle pair in the same task; [P1-T6] checks pairs, manifests and the generator; [P1-T12] hashes every pair. The cycle changes no fact the execution-environment brief states, so no brief-update task is needed; [P1-T12] still hashes the six copies.
- File size: a corpus addition could push a corpus file past 500 lines. Prevention: [P1-T5] holds each corpus file under 500 lines; [P1-T12] counts physical lines against 800.
- Test isolation: removing `-Force` could expose a stale module instance loaded by another file in the same shard. Prevention: the affected suites already `Remove-Module` the docs modules in their teardown; gates are one `Invoke-PoshQCParallelTest` run, one `pytest -n auto` run and `Invoke-PoshQCLeakScan`, each re-run only after a fix; a leak is fixed in both the leaking and the affected suite with no new allowlist entry ([P1-T11]).
- CI-only behavior: the parity suite also runs in `poshqc / PowerShell hook suites (Linux)`, and `origin/main` may advance again. Prevention: corpus additions follow the [P5-T1] standard (LF, no drive letters, no `artifacts/` reads, no file writes); the executor does not merge again, and the single-registration assertions of the approved plan fail any CI run carrying a registration beside the dispatcher.
- Evidence: a record overwritten or a cost report re-run. Prevention: every artifact is a new stamped file with `Timestamp:`, `Command:`, `EXIT_CODE:`, `Output Summary:`; [P1-T12] proves the three cost artifacts are unchanged; no absolute path or host name is recorded.
