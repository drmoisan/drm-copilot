Design: `Get-RunbookCountedBlock` joins a physical line that ends in a continuation character (` \`, `` ` ``, or `^`) to the next physical line, so `Command` holds logical commands. `Get-RunbookCommandToolName` splits one logical command into segments on `&&`, `||`, `;`, and `|` (separators inside single or double quotes do not split), skips leading `NAME=value` assignments in each segment, returns nothing for a segment whose first token is `cd`, `pushd`, `popd`, `export`, `set`, `source`, `.`, `echo`, or begins with `$env:`, and otherwise resolves the segment as today. A single-segment command returns the same single name as before; a multi-segment command returns one name per tool segment. `Get-RunbookCommandVersionFinding` wraps the call in `@(...)` and adds every returned name to the block's tool list.
