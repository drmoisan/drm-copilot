## Execution decisions

- Root grants and tool authorizations are the only identity sources; a request's `authorization_ref` or `root_grant_ref` selects a record the service already consumed and is refused when caller-supplied. The service holds consumed records in memory for one use because the runtime call runs after the gate; a reference without a consumed record is refused with `DISCOVERY_HOST_BINDING_REQUIRED`.
- `toolInputs` (the raw MCP input) rides on the resolved prepare, doctor and sentinel inputs so the service recomputes the digest the hook used; an extension command supplies none, so prepare is refused there and doctor answers `context-missing`. The VS Code artifact command suite asserts the root call runs as `local-user` and the bound call is refused.
- The sentinel tool and the `sentinel` operation were added to the `tool-authorization` schema enums (at the end, so the fixture order holds) because tests/discovery_runtime/test_tool_authorization_fixture.py derives the tool table from those enums; the `service-request` operation enum is unchanged, so a `sentinel` host request stays schema-invalid and the gate never writes a tool authorization for the sentinel. The packaged schema copy was regenerated with `build_discovery_runtime --stage-only`.
- Refusals raised on the service path (`DISCOVERY_HOST_BINDING_REQUIRED`, `AUTHORIZATION_*` from the root-grant module, `AUTHORIZATION_IDENTITY` from the identity module) carry their code at the start of the message so the MCP failure summary names the class; the gate's existing re-wrap is unchanged.
- The in-memory store fake `MemoryStoreIO.listEntries` now lists immediate child names including sub-directories, as `readdirSync` does, and `writtenPaths()` excludes listings; the fake had modelled files only, which hid the session scan.
- `rejects an out-of-enum report_type` in ET/mcp-tools.discovery.test.ts now expects `AUTHORIZATION_OPERATION_UNKNOWN`: the gate derives the controlled operation before the resolver runs for a root call, so the refusal moves to the gate; the service is still never called.
