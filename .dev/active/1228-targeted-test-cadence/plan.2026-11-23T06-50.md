## Size Justification

The plan has 25 tasks, above the 20-task guideline. Phase 0 needs one static artifact per language and one `Phase 0 baseline` run per gate (five tasks), and the final phase repeats that shape with scope and self-review (seven tasks). Phase 1 holds eleven surface families that differ in source kind (hand, harness source, `.agents` source, generator run) and in pinning test, plus the search evidence, the ledger, and the gate; merging families would mix unrelated acceptance and selections, and the ledger chain forbids splitting Phase 1 into gated phases.
