**Valid-read rule (fixed).** Each run artifact evaluates the following tokens independently, in this order, and records every one that holds:
1. `RUN-NOT-PERFORMED` — no `mcp__drm-copilot__run_poshqc_test` call was made in the task (D-ISO step 4 not reached; the artifact records `MCP-DISPOSITION: not-called`).
2. `ISOLATION-REFUSED` — a hook refused the D-ISO revert command.
3. `ISOLATION-NOT-APPLIED` — the D-ISO step-3 porcelain check or the D-ISO step-3 `git diff --quiet` check failed.
4. `FILE-NOT-REWRITTEN` — the run did not rewrite the coverage file under D-COV-FRESH (either value unchanged, or the post `stat` failed because the file is absent).
