### AC-7 judgment

AC-7 reads: "Every existing test file under `tests/scripts/claude-hooks` and `tests/scripts/codex-hooks` passes without modification (no diff to any pre-existing test file in the branch)", verified by "`git diff --name-status main` showing only added test files under those folders". After cycle 1 the parenthetical and the stated verification step are literally false: 18 pre-existing suites are modified.

The reviewer grades AC-7 PASS with a recorded deviation, for these reasons:

1. The purpose of AC-7 is regression non-interference: the new leg must not force any existing suite's assertions, rows, mocks, or expectations to change in order to pass. That holds. No assertion, row, mock, or expectation changed; the diff is additive teardown only (0 deleted lines; every added line is an `AfterAll`, the reset call, the helper dot-source, a comment, a brace, or blank).
2. The teardowns do not adapt existing tests to the new production code. They repair a pre-existing defect on `main`: the 18 suites leave a stale module binding for every later file in a shared process. The new suite exposed that defect; it did not create it.
3. The repository test-independence rule (`.claude/rules/general-unit-test.md`, Independence) and the cycle-1 remediation inputs ("fix it in the new suite (and, when the cause is a leak, in the suite that leaks state as well ...); ... do not edit any existing suite unless it is the proven leaker") require the leaker-side fix. Each edited suite is a proven leaker by the diagnosis, which the reviewer confirmed against the hook source and with a single-process probe. Repository policy and the review-issued cycle inputs take precedence over the spec's verification wording, which was written before the leak was known.
4. Classifying this as blocking would need either reverting the teardowns, which violates the test-independence rule, or amending the AC text, which changes nothing in the delivered behavior.

The deviation is recorded as a Minor finding in the code review. The recommended action is to note it in the PR description. AC-7 stays checked.
