## Design: decision D19 (subcommand position)

Cause (F3): the subcommand loop of `Test-OrchestrationGateMentionHostRecord` takes the first later token that does not start with `-` as the subcommand. The value of a value-taking global option is such a token, so `npm -w search run lint` reads `search` as the subcommand and drops the hit. Which options take a value differs per tool and release, so the gate cannot skip option values from a list without reopening the finding for an unlisted option.

**Rule.** A subcommand-scoped host (`git`, `npm`, `pip`, `pip3`, `poetry`: every key of `Subcommand` in `Get-OrchestrationGateMentionHostTable`) is a mention host only when the token immediately after its command word, after transparent-wrapper removal (`Skip-CommandLineTransparentWrapper`), is a listed subcommand (ordinal, as today). Any token before the subcommand (a flag-only option, a value-taking option in separate or attached `=value` form, or its value) keeps the hit classified. No listed subcommand starts with `-`, so the rule needs no option test. The executing-option scan of the same function, `Get-OrchestrationGateMentionHostTable`, and every other rule are unchanged.

**Class covered.** Every subcommand-scoped host of the table, with each value-taking global option in ordinary use whose value can equal a listed subcommand: `npm -w`, `--workspace`, `--prefix`, `--loglevel`; `poetry -C`, `--directory`, `-P`, `--project`; `pip` and `pip3` `--cache-dir`, `--log`; `git -C`, `--git-dir`, `--work-tree` (rows ED-97 to ED-116, each unclassified at head by trace and a stage-1 hit, so classified at the merge base). `git -c` is not a row: its value has the form `name=value` and never equals a subcommand. Attached `=value` forms already resolve to a non-listed word at head; rows ED-117 to ED-120 pin them so a fix that strips only separate values cannot pass.

**Bound and cost.** Stage 1 is unchanged and D19 only turns host records into non-host records, which only adds confirmations through rule 3, the D16 consumer walk, and the D17 operand and pipeline-mate conditions; the classified set lies between the head set and the merge-base set (AC-3 holds), and every row on which head and merge base agree keeps its value. Cost: a mention through a subcommand-scoped host with any option before its subcommand is classified, as at the merge base: `git --no-pager log --grep pytest`, `npm --silent ls prettier`, `pip -q show black`, `poetry --no-ansi show pytest`.

**FP analysis.** The subcommand-scoped FP rows FP-07 (`git log`), FP-08 (`git grep`), FP-11 (`poetry show`), FP-12 (`pip show`), and FP-13 (`npm ls`) carry the subcommand directly after the command word; no other FP row is led by a subcommand-scoped host; all 17 stay unclassified. NG-01 to NG-09 miss stage 1. ED-01 to ED-96 stay classified. **AC reading:** AC-2's table includes ED-97 to ED-120; AC-5's D2 table is unchanged in data (only its lookup changes). No AC text changes.
