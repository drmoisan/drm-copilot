## Premise Correction

NB1 names only `Get-EpicProgressTldrLine` in `SKILLDIR/Get-EpicProgressReport.Render.ps1`. The InProgress rows that the Now line reads are built by `Get-EpicProgressTypeEstimate` in `SKILLDIR/Get-EpicProgressReport.Metrics.ps1` and carry `ElapsedSeconds` but not the step start, so Render cannot tell a missing start from a zero elapsed time. - Anchor retention rule (NB4): an item that has a `merge` step whose status is `done` has no entry in the returned `Items` table; `ItemsChanged` becomes true only when the stored state held an entry for that item. The `durations` ledger is unaffected.
