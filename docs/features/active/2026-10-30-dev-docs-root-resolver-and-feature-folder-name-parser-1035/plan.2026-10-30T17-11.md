## Size Justification

This child is one cross-runtime contract change: one configured key read by about 100 production consumers in three runtimes (the research inventory plus the seven routed refresh-inventory files), with mirrors, a write-scope contract and CI scope. The owner decided the child is not split. Each task covers one consumer group with its tests so that each binary outcome stays checkable, and the current contract adds a `[phase-gate]` task to each of eight phases; the result is 82 canonical tasks (above the legacy guideline of 40 for this plan stamp) in 430 physical lines (above the legacy 400 because of the traceability tables that the design check requires, the ledger and S-9 Recorded Decisions D-P17 to D-P21, the per-test dispositions that changed existing behavior requires, and the per-consumer WorkspaceRoot and Codex import-order design added by the 2026-11-15 revision). The Codex generator run counts as one task (P7-T4).
