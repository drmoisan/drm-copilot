## Design Summary

- Rule added: the preflight executor runs one named pass, the design check, inside the existing single pass. For each rule, parameter, and boundary in `spec.md` (for a minor-audit folder, `## Acceptance Criteria` of `issue.md`), it names the task that implements it and the test that would fail if the rule were broken. A gap is a substantive defect. No delegation, no artifact, no hook, and no validator change.
- Bullet text, quoted because tests assert it, placed after the `**Return substantive defects only, all of them.**` bullet of `### Single-Pass Preflight`: `**Run the design check.** Within the same single pass, with no new delegation and no new artifact, the preflight executor reads the feature's spec.md (or the Acceptance Criteria of issue.md when the folder has no spec.md) and, for each rule, parameter, and boundary it states, names the task that implements it and the test that would fail if the rule were broken.
