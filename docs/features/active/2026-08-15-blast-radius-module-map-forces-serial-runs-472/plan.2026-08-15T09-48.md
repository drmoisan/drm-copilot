2. **Do not modify `.github/instructions/**`** (canonical policy) or `.claude/rules/**`.
3. **File size limit:** no production, test, or reusable script file may exceed 500 lines. `extensions/drm-copilot/test/lib/push-down/claude-config-carriage.test.ts` measured 489 lines at planning time; Phase 5 therefore begins with a behavior-preserving compaction task before any addition to that file.

5. **Evidence locations:** all evidence artifacts are written under `docs/features/active/2026-08-15-blast-radius-module-map-forces-serial-runs-472/evidence/<kind>/` per `evidence-and-timestamp-conventions`. Timestamps use `yyyy-MM-ddTHH-mm`; `<ISO-8601>` in a filename below means the execution-time stamp in that format. Every command-step artifact records `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`.
6. **Toolchain restart rule:** within each language loop (TypeScript: format → lint → typecheck → test; Python: black → ruff → pyright → pytest; PowerShell: PoshQC format → analyze → test), if any step fails or modifies files, restart that language's loop from its first step until a clean single pass completes. `EXIT_CODE: SKIPPED` is never a passing outcome for any command task in this plan. Carve-out: the restart-on-failure rule does NOT apply to the `[expect-fail]` TypeScript runs P3-T5 and P4-T3, whose documented red state is planned and evidenced; the TypeScript loop restart rule takes effect from Phase 5 onward.
7. **`poetry run python -c` invocations must be single-line.** Multi-line `-c` strings under `poetry run` are a silent no-op on this host.
8. **Self-referential blast radius:** `config/blast-radius.json` is itself a declared shared surface; this item's declared blast radius must enumerate `config/blast-radius.json` in `shared_surfaces`.
