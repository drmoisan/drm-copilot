## 1. Scope and decisions

- **Start-guard predicate (research section 2.1).** A dependent feature is treated as started when its `worktree_created_at` is a string (any string, including empty), or when its `merge_status` is not equal to the literal `"not_started"` (a missing key, `null`, or any other non-string value therefore counts as started). The guard is evaluated once per dependent, immediately after the existing non-string `feature_folder` / non-list `depends_on` skip, and an unstarted dependent is skipped before its edge loop. The epic predicate deliberately does not reuse the parallel `_has_started` in `scripts/dev_tools/_parallel_orchestrator_state_cohort_barrier.py`, which treats an absent `merge_status` as not started; the helper docstring records this difference.
- **Dependency status check.** Python checks `isinstance(dep_merge_status, str)` before set membership, so that the Python status term reads `not isinstance(dep_merge_status, str) or dep_merge_status not in MERGED_STATUSES`, matching TypeScript `typeof depMergeStatus !== "string" || !MERGED_STATUSES.has(depMergeStatus)`.
- **Error strings (AC-4), verbatim.** Exactly one error per violated edge; the status case takes precedence when both hold.
  - Status case: `EPIC_WAVE_BARRIER_VIOLATION: {folder} is treated as started while dependency {dependency} is not merged`
  - Timing case (dependency status is merged, and its `merge_confirmed_at` string is later than the dependent's `worktree_created_at` string): `EPIC_WAVE_BARRIER_VIOLATION: {folder} worktree_created_at precedes dependency {dependency} merge_confirmed_at`
  - `{folder}` is the dependent's `feature_folder`; `{dependency}` is the raw `depends_on` entry rendered with Python `str()` / TypeScript `String()`. The TypeScript template literals are `` `EPIC_WAVE_BARRIER_VIOLATION: ${folder} is treated as started while dependency ${String(dependency)} is not merged` `` and `` `EPIC_WAVE_BARRIER_VIOLATION: ${folder} worktree_created_at precedes dependency ${String(dependency)} merge_confirmed_at` ``.
  - The two single-line search tokens used by [P2-T12] are quoted here: "is treated as started while dependency" and "worktree_created_at precedes dependency".
