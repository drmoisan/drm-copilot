## Design (R2)

- New `Resolve-RegenerationExecutable -Name [-Resolver]` in the adapter: returns the path the `-Resolver` scriptblock returns for `Name`, and throws `executable <Name> cannot be resolved` when that value is null or empty. The `-Resolver` default is one `Get-Command -Name $Name -CommandType Application -ErrorAction SilentlyContinue` pipeline that takes the first match's `Source` (PATHEXT on Windows, PATH on Linux).
- New pure `Get-RegenerationProcessStartSpec -ResolvedPath -ArgumentList -ComSpec` in the adapter: returns one object with `FileName` and `ArgumentList`. A path whose extension is `.cmd` or `.bat` (ordinal, case-insensitive) gives `FileName` = `ComSpec` and `ArgumentList` = `/d`, `/c`, the resolved path, then each argument as its own item; it throws when `ComSpec` is empty, and throws when an argument contains whitespace, a double quote, or one of `&|<>^%()`, because `cmd.exe` cannot receive such an argument unchanged (premise refinement of AD-2, reported to the orchestrator). Every other path gives `FileName` = the resolved path and the arguments unchanged.
- The `-Invoker` default calls the two functions (`-ComSpec $env:ComSpec`), constructs `ProcessStartInfo` from the spec's `FileName`, and adds each spec `ArgumentList` item; the rest of the default is unchanged. A throw from either function reaches `Invoke-RegenerationProcessStep`, which reports `Started = $false` as today.
- Placement: both functions stay in the adapter, since `RegenerationConfig.psm1` (config validation) and `RegenerationDelta.psm1` (staged-delta checks) do not own process starts, and a new module would change the pinned guarded-import order of check (f). Expected size of the adapter: about 770 logical lines (711 today), at most 790; no compaction is needed.

## Planner Notes

- Premise refinement of AD-2: `cmd.exe` strips the outer quotes of its command tail when more than two quote characters occur, so a quoted batch path followed by a quoted argument cannot reach the batch file unchanged; the spec function therefore refuses such arguments instead of passing them, which also closes metacharacter injection.
