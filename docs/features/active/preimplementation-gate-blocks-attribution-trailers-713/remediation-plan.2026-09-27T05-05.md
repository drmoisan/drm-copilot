## 1. Decisions (operator approval 2026-09-26: no further approvals required)

- **R1 — Fail-closed design: any typographic quote makes the line unresolvable.** The seven characters U+2018, U+2019, U+201A, U+201B, U+201C, U+201D, U+201E are added as a constant, and the existing escaped-quote early return in `Test-OrchestrationCommandTextUnresolvable` also answers true when the command text contains any of them. Rationale: (a) it satisfies the ruling's required behaviour, because every `$` and backtick in a line carrying a typographic quote is denied, as on the base commit; (b) it also closes the tokenization desynchronization that does not need `$`: under a PowerShell host, `git commit -m 'a’ src/prod.ts ‘b' -- docs/features/active/x/plan.md` ends the first string at U+2019 and passes `src/prod.ts` to git as a pathspec, while the scanner reads one single-quoted message; the narrower "withdraw the single-quote allowance" design would leave that form admitted; (c) it is one extra condition on an existing early return, with no new loop state; (d) the ruling states that a typographic quote with no `$` or backtick "need not be denied", which permits denying it. Cost: a message containing a typographic apostrophe falls back to the caller's pre-change deny; the documented forms use ASCII quotes.
- **R2 — Net-zero line delta (497 lines).** AC7 requires the canonical file to be "not longer than its line count measured immediately before the edit" (497). An added line would falsify AC7, so the constants comment is compressed from four lines to three to make room for the new constant, and every other change replaces whole lines one for one.
- **R3 — Character construction.** The helpers constant is `[char[]]@(0x2018, 0x2019, 0x201A, 0x201B, 0x201C, 0x201D, 0x201E)` (the same integer-to-char conversion as `[char]0x2018`, written once for seven values); the test rows use `[char]0x2018`, `[char]0x2019`, `[char]0x201C`, `[char]0x201D`. Both files stay ASCII (rule 6).
- **R4 — Test rows.** Three deny rows are added (section 4), each admitted by the helpers at head and therefore failing before the fix: a typographic-single-quoted `$(...)`, a typographic-double-quoted `$(...)` between typographic single quotes, and a typographic single quote exposing a non-exempt pathspec (pins R1(b)). The allow row required by F1 is the existing row `admits a single-quoted subject containing a dollar sign and a command substitution` (test file line 48, `'docs: costs $5 and $(x)'`, straight single quotes, no typographic character), which stays unchanged.
- **R5 — Skill documents.** The typographic-quote rule fits in one sentence, so it is appended to the existing `Quoting rules:` paragraph line of each skill document (no line-count change), and the two bundle mirrors are byte copies.
- **R6 — Comments.** CR-3 (`Test-ExemptOrchestrationStagingCommand` comment), the `Test-OrchestrationCommandTextUnresolvable` docstring, the early-return comment, and the constants comment are corrected in place within the same line count.
