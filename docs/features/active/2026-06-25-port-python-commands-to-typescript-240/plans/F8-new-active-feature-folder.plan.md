## Parity Notes (binding design decisions)

These notes capture the exact observable behavior of the bundled Python that the port MUST reproduce.

### Filesystem seam (do NOT widen the F1 `FileSystem` interface)

The bundled Python `FileSystem` protocol (in `new_active_feature_folder_models.py`) exposes `exists`, `ensure_dir`, `copy_file`, `copy_tree`, `list_files`, `read_text`, `write_text`, `move`. The F1 `src/lib/file-system.ts` `FileSystem` interface exposes only `glob`, `isFile`, `readTextFile`, `writeTextFile`, `ensureDir` — it has NO `exists`, `copyFile`, `copyTree`, `listFiles`, `readText`, `writeText`, or `move`. To avoid widening the shared F1 surface (mirroring the F6/F7 decision), the port MUST define a port-local interface `FolderFileSystem` in `models.ts` with the methods the workflow needs:

- `exists(path: string): boolean` — port of `exists`.
- `ensureDir(path: string): void` — port of `ensure_dir` (`mkdir(parents=True, exist_ok=True)`; idempotent).
- `copyFile(src: string, dest: string): void` — port of `copy_file`; ensures the destination parent directory exists, then copies the file bytes.
- `copyTree(src: string, dest: string): void` — port of `copy_tree`; recursively copies every FILE under `src` to `dest` preserving each source-relative path (directories themselves are skipped; only files are copied via `copyFile`). This is the contract locked in by `test_real_filesystem_copy_tree_preserves_relative_paths`.
- `listFiles(path: string): string[]` — port of `list_files`; returns the regular files directly under `path` (non-recursive), or `[]` when the directory is missing (locked in by `test_real_filesystem_list_files_returns_empty_for_missing_path`).
- `readText(path: string): string` — port of `read_text` (UTF-8).
- `writeText(path: string, content: string): void` — port of `write_text`; ensures the parent directory exists, then writes UTF-8.
- `move(src: string, dest: string): void` — port of `move`; ensures the destination parent directory exists, unlinks the destination FIRST when it already exists as a file, then moves/renames the source (locked in by `test_real_filesystem_move_replaces_existing_destination_file`: the observed call order is `mkdir`, `unlink`, `replace`).

Provide `RealFolderFileSystem implements FolderFileSystem` backed by `node:fs`/`node:path` for production. Tests inject a `Map`-backed fake (tracks files, created dirs, and moves; `move` of an absent source throws; `readText` of an absent path throws; `copyTree`/`listFiles` operate on the in-memory tree). Do NOT add any of these methods to the shared F1 `FileSystem` interface. The port MAY reuse F1 `toPosixPath` for slash normalization.

### Path handling (string paths, not a `Path` object)

The Python source uses `pathlib.Path` throughout. The TS port uses forward-slash POSIX path strings (consistent with the F1 `file-system.ts` and F6/F7 ports). Path joins use a small POSIX-join helper (or `node:path.posix.join` normalized via `toPosixPath`); `basename`/`stem`/`suffix`/`relative_to` are computed with `node:path` helpers and normalized to forward slashes. The `ActiveFolderResult` `target` and `potentialIssuePath` are path strings (Python returns `Path` objects; the TS contract is the equivalent string form). `code_launcher` receives path strings; the Python launcher maps each path to `as_posix()` form (`str(file_path).replace("\\", "/")`), which the port replicates.

### `markdown.ts` parity (port of `new_active_feature_folder_markdown.py`)

Port each function with byte-identical regexes and formats:

- `formatChecklist(text)`: split on line breaks (mirror Python `splitlines()`), trim each line, skip blanks; a line matching `/^-\s*\[?\s*\]/` is kept verbatim; a line starting with `-` is kept verbatim; otherwise prefix `- [ ] `. Join with `\n`.
- `getSection(content, name)`: extract the body under a `## <name>` block up to the next `##` or end-of-string; regex `^\s*##\s+<escaped-name>\s*\r?\n(.*?)(?=^\s*##\s+|\Z)` with multiline+dotall semantics; return the trimmed group or `""`. Use a `RegExp` with `m` and `s` flags and `[\s\S]` / dotAll; escape the name.
- `upsertWorkModeMarker(content, mode)`: remove any existing line matching `/^- Work Mode:\s*(minor-audit|full-feature|full-bug|full)\s*$/`; then insert `- Work Mode: <mode>` followed by a blank line directly above the first line whose left-trimmed form starts with `## `; if there is no `## ` heading, append a trailing blank line (when the last line is non-empty) then the marker line. Join with `\n`. Reproduce the exact insertion ordering (marker then blank line, both inserted at the heading index).
- `setSection(content, name, body)`: if `body` is empty/whitespace, return `content` unchanged; if a `## <name>` block exists, replace its body with `<body>\n\n` (regex `(^##\s+<escaped-name>\s*\r?\n)(.*?)(?=^\s*##\s+|\Z)`, count 1); else append `## <name>\n<body>\n` after trimming the existing content (adding `\n\n` separator when non-empty). **Escape-safe replacement (regression):** the replacement body MUST be inserted literally — `body` may contain backslash sequences (e.g. `C:\Outlook\Objects`) that must NOT be interpreted as regex replacement escapes. Use a function-form replacement callback (not a replacement string) so `$`/`\` in the body are preserved verbatim. This is the bug locked in by `test_set_section_preserves_backslashes_in_replacement_body`.
- `prependToSectionBody(sectionBody, prefix)`: trim the prefix; if empty return the body unchanged; if the trimmed body is empty return `<trimmedPrefix>\n`; else return `<trimmedPrefix>\n\n<trimmedBody>\n`.
- `updateSectionBody(content, sectionName, updater)`: returns `[newContent, changed]`. Find the `## <sectionName>` block; if absent return `[content, false]`; apply `updater(body)`; if unchanged return `[content, false]`; else replace with `<header><updatedBody>\n` and return `[newContent, true]`. **Escape-safe replacement (regression):** use a function-form replacement callback so the updater output (which may contain backslashes) is inserted literally. This is the bug locked in by `test_update_section_body_preserves_backslashes_in_updated_body`.
- `setHeaderPlaceholder(content, featureName, issueField, ownerField, updatedField, statusField?, parentField?, versionField?)`: port the full placeholder/header substitution chain verbatim. Replace every `PLACEHOLDERS` entry with `featureName`; replace `<issue>` with `issueField`; conditionally replace `<parent-id>`/`<status>`/`<version_number>` when the corresponding field is provided; apply the `#`?<id>`?` regex, `<#id or TBD>`, and `#<tracking-issue>` substitutions to `issueField`; rewrite `Issue`/`Owner`/`Parent (optional)`/`Last Updated`/`Date`/`Status`/`Version` metadata lines (both the `**Bold:**` and plain `- Label:` forms) with the byte-identical replacement formats and the exact multiline regexes from the Python source; replace `<yyyy-MM-ddTHH-mm>` with `updatedField`; and finally, when no `Issue` metadata line is present, prepend `- Issue: <issueField>\n` to the content. Every regex (including the `(?:name|<name>|.*)` owner alternations and the `Date:\s+YYYY-MM-DD` literal) MUST be byte-identical. All these replacements MUST be escape-safe with respect to the field values.

### `flow.ts` parity (port of `new_active_feature_folder_flow.py`, `create_active_folder`)

Port `create_active_folder` into `createActiveFolder(options)` preserving this control flow, every emitted line, and every error message. Options: `{ featureName: string | null; featureType?: string; issueNumber?: string | null; force?: boolean; activeFileForFeatureName?: string | null; workspace?: string; fs?: FolderFileSystem; issueFetcher?: (n: string) => IssueMeta | null; codeLauncher?: (files: readonly string[]) => boolean; nowProvider?: () => Date; workMode?: string; templateRoot?: string | null; emit?: (msg: string) => void }` with production defaults (`featureType = "feature"`, `force = false`, `workMode = "full"`, `RealFolderFileSystem`, `defaultIssueFetcher`, `defaultCodeLauncher`, workspace = `resolveWorkspace()`, no-op `emit`).

1. Validate `featureType` against `{feature, refactor, epic, bug}`; on miss throw `Error("Type must be one of: feature, refactor, epic, bug")` (byte-identical).
2. Resolve `workspacePath` and `filesystem` from options/defaults.
3. Resolve the feature name: default `resolvedFeatureName = featureName`, `featureNameSource = "manual"`. When `activeFileForFeatureName` is provided: build the `auto_resolve_error` string `Select a promoted issue markdown file under docs/features/potential/promoted or supply --feature-name directly.`; resolve the active-file path (relative paths join the workspace); compute `promotedRoot = workspace/docs/features/potential/promoted`; determine `isInPromoted` by a relative-to check; if the suffix is not `.md` (case-insensitive) OR not in promoted OR the file does not exist, throw `Error(auto_resolve_error)`; else `resolvedFeatureName = <stem of active-file>`, `featureNameSource = "active-file"`.
4. If `!resolvedFeatureName` throw `Error("feature_name must be provided when --active-file-for-feature-name is not used")` (byte-identical).
5. `validateFeatureName(resolvedFeatureName)`; emit `Feature name source: <featureNameSource>`.
6. Resolve `templateDir`: when `templateRoot` is provided, `templateRoot/<featureType>`; else `workspace/docs/features/templates/<featureType>`. If `!filesystem.exists(templateDir)` throw `Error("Template folder not found: <templateDir>")` (byte-identical; the Python raises `FileNotFoundError`, which the CLI `main` reports as `Aborted: required file not found: <exc>` — the TS port surfaces this as an `Error` and the service-call helper preserves the failure surface confirmed in P0-T2).
7. `potentialFile = findPotentialFile(resolvedFeatureName, workspace, fs)`; `potentialContent = potentialFile ? fs.readText(potentialFile) : ""`.
