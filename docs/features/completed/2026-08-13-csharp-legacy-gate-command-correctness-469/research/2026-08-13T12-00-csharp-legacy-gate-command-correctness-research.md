## 6. Research Question 4 — Exact Corrected Command Text

### 6.1 Platform-property quoting

All four files must carry the whole-argument form `"/p:Platform=Any CPU"`, replacing the current value-only form `/p:Platform="Any CPU"`:

- AC4/AC5 specify the whole-argument form verbatim, and AC10 tests assert exact substrings, so one canonical form is required.
- Rationale for the form itself: the whole-argument form is a single quoted token in both cmd.exe and PowerShell and reaches MSBuild identically; the value-only form is tokenized differently per shell (PowerShell strips the interior quotes during parsing and re-quotes at its own discretion), which makes the documented command shell-dependent. MSBuild accepts either spelling, so the change is a portability normalization, not a semantic change.

### 6.2 Solution placeholder

Preserve each file's existing choice: Claude-surface files use `<solution>.sln`; Codex-surface files use the literal `TaskMaster.sln`. Do not normalize.
