## Size Justification

The item delivers one PreToolUse hook with two modes and a ledger guard, a stop-hook check, two pure modules, an exported validity function, registration, packaging, and documentation across six mirrored owner-directive copies, six brief copies, three skills, one rule, and nine agents, with 48 spec criteria. Splitting into an epic would put the hook and its documentation in separate merges while the documentation describes the hook, so the plan stays one item at 32 tasks.
