### Phase 2 — PoshQC Vendored Coverage Check and Derivation

- [ ] [P2-T1] Create `PQ/PoshQC.VendoredCoverage.psm1` (target at most 400 logical lines; Windows PowerShell 5.1 compatible) with comment-based help on each function:
  - `Get-PoshQCCanonicalContentHash -Bytes` normalizes at byte level (each `0D 0A` to `0A`, then each remaining `0D` to `0A`; nothing else) and returns lowercase hex from `[System.Security.Cryptography.SHA256]::Create().ComputeHash([byte[]])`.
  - `Read-PoshQCFileByte -Path` (default read seam, `[System.IO.File]::ReadAllBytes`) and `Test-PoshQCReparsePoint -Path` (default seam, `ReparsePoint` attribute test).
  - `ConvertFrom-PoshQCPushDownManifest -Bytes` returns path-to-`sha256` pairs; it throws, with `.push-down-manifest.json` in the message, for invalid JSON, a missing or non-semver `schema_version`, a major other than 1, a missing `files` object, an entry `sha256` that is not 64 lowercase hex, and a key that is absolute (leading `/`), a drive-letter path, a UNC path (leading `//` or `\\`), or has a `..` segment; unknown top-level and per-file fields are ignored.
  - `Get-PoshQCVendoredCoverageStatus -Root -CandidatePaths [-ReadBytes] [-TestPathExists] [-TestReparsePoint] [-WarningLogger]` returns one record per manifest entry and per candidate not in the manifest, each with `path`, `status` (`exempt`, `modified`, `missing`, `unlisted`), `manifest_sha256`, `actual_sha256`, sorted ordinally by `path`; key matching is ordinal and case-sensitive; a reparse point is `modified` with `actual_sha256` null; an absent manifest logs exactly one warning naming `.push-down-manifest.json` and reports every candidate `unlisted`.
  - `Get-PoshQCVendoredCoverageOptIn -Parsed -ConfigRelativePath` returns `$false` when `exempt_unchanged_push_down_files` is absent, the value when it is a boolean, and throws naming the configuration file otherwise.
  - `Resolve-PoshQCVendoredCoverageExemption -Root -Files [-GetStatus]` takes file-set records (`RelativePath`, `FullPath`), removes each file whose `RelativePath` ordinally equals a record with status `exempt`, and returns `Paths` (remaining `FullPath` values) and `Exemptions` (all records).
  - `ConvertTo-PoshQCVendoredCoverageReportJson -Exemptions` returns `{"entries":[...]}` with entries sorted ordinally by `path`, LF line endings and a trailing LF, no timestamp and no root.
