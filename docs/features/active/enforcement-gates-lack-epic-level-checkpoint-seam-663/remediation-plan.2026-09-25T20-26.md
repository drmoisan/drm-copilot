### 2.1 R1 — `Test-OrchestrationCommandTextUnresolvable` fails closed on backslash escapes

File: `.claude/hooks/enforce-orchestration-preimplementation-gate-helpers.ps1` (488 lines), byte-copied to `.codex/hooks/enforce-orchestration-preimplementation-gate-helpers.ps1`, `extensions/drm-copilot/resources/claude-customizations/.claude/hooks/enforce-orchestration-preimplementation-gate-helpers.ps1`, and `extensions/drm-copilot/resources/codex-and-agents-customizations/.codex/hooks/enforce-orchestration-preimplementation-gate-helpers.ps1`.

Rule (remediation-inputs R1 "Required change"): the function returns `$true` when (a) the text contains a backslash immediately followed by `"` or `'` anywhere, or (b) a backslash occurs inside a double-quoted span. Arm (a) closes the unquoted forms `x\"` and `x\'`, where the shell reads a literal quote but the scan would open a span; arm (b) closes CR-1, where the scan closes a double-quoted span at `\"`. No escape is modelled.


### 2.2 R2 — head-matched legs ignore a text branch signal

File: `.claude/lib/worktree-resolution/EpicScopeResolution.psm1` (366 lines), byte-copied to `extensions/drm-copilot/resources/claude-customizations/.claude/lib/worktree-resolution/EpicScopeResolution.psm1`.

Chosen option (remediation-inputs R2 permits either): when `-MatchWorktreeHead` is set, the matched branch and the `MERGE_HEAD` probe are decided from the effective worktree only (selector worktree, else session root), and any text branch signal is ignored.
