## Conventions Used in This Plan

- `<FEATURE>` means `docs/features/active/2026-09-29-issue-763-parallel-skill-cli-port-follow-ups-791`. Every evidence artifact is written under `<FEATURE>/evidence/<kind>/` only (`baseline`, `regression-testing`, `other`, `qa-gates`). `<timestamp>` is the execution time in `yyyy-MM-ddTHH-mm` form.

- All commands run from the worktree root. Shell commands run in Git Bash (`sh` is GNU bash there). In an agent-isolated worktree the isolation guard refuses command text containing the words for the bash, PowerShell, or WSL executables and refuses heredocs; this plan therefore runs bash scripts as `sh <file>`, runs bats as `npx --yes bats <file>`, and runs PowerShell through a throwaway runner pair in the session scratchpad (never in the repository), defined in [P0-T13].
- `<scratchpad>` is the session scratchpad directory supplied by the runtime. Files written there are throwaway runners and tool output; they are not repository files and are not evidence.
- Coverage JSON reports go to `artifacts/python/` (gitignored tool output, already the `addopts` LCOV destination). They are tool output, not evidence. Line and branch percentages are derived from the JSON `totals` object only: line % = `covered_lines / num_statements x 100`; branch % = `covered_branches / num_branches x 100`. The terminal `Cover` column is a combined figure and is never used as either value.
- `git diff` scope checks are anchored with `--merge-base origin/main`. `origin/main` is fetched once in [P0-T2] and is not fetched again during this plan, so the anchor does not move.
- Restart rule for Phase 8: if any Phase 8 command task fails or changes a file, fix the cause and restart Phase 8 from [P8-T1]. The loop is complete only when [P8-T1] through [P8-T13] pass in one uninterrupted pass.
