## Design Decisions (planner)

- Open decision 1 (untracked with an existing target): guard (b) applies (spec verdict table).
- Open decision 2 (duplicate `target_path`): refused with `REFUSED-WOULD-REGRESS`; the first record is planned, later records are refused. A target counts as seen once a record reaches the duplicate check, whatever the decision outcome.
- Open decision 3: no `ACTION|preserve-merge` record; a merged record reports `OK` and may write a `cleanup-worktrees: merged <tgt>` stderr note.
- New library `.claude/skills/cleanup-merged-worktrees/scripts/cleanup_worktrees_preserve_merge_lib.sh` (MLIB) defines: `preserve_merge_is_subsequence` (needle content, haystack content; trailing-CR tolerant, unterminated final line counts, empty needle passes), `preserve_merge_extra_within` (merged, main, worktree, base contents; G3 multiset containment), `preserve_merge_refuse` (emits `ACTION|preserve-stage|<tgt>|REFUSED-WOULD-REGRESS` on stdout, a `cleanup-worktrees: refused <tgt>: <reason>` stderr line, sets `PRESERVE_EXIT=1`, returns 1), `preserve_merge_check_duplicate` (global `PRESERVE_SEEN_TARGETS`), `preserve_merge_resolve_base` (echoes the base blob id or returns 1; returns 1 without any git call when `source_path` differs from `target_path`; empty git stdout counts as unavailable), and `preserve_merge_decide` (sets `PRESERVE_STAGE_MODE` to `copy` or `merge` and `PRESERVE_STAGE_OID`, or refuses).
- Asserted stderr reason tokens: `G1`, `G2`, `G3`, `guard-b`, `merge-file rc=`, `duplicate-target`.
- Git call shapes in the decision (all through `cleanup_wt_git`, none with `-f` or `--force`): `-C <wt> rev-parse --verify --quiet HEAD`; `-C <cwt> merge-base <wt-head> HEAD`; `-C <cwt> rev-parse --verify --quiet <mb>:<src>`; `-C <cwt> cat-file blob <oid>`; `-C <cwt> hash-object -w --path=<tgt> -- <tgt>`; `-C <wt> hash-object -w --path=<tgt> -- <src>`; `-C <cwt> merge-file --union --object-id <main-oid> <base-oid> <wt-oid>`. No process substitution is passed as a git file argument.
- Stub keys added to `tests/fixtures/cleanup_worktrees/stub-bin/git` (existing call shapes keep their keys and default responses): `merge-base <a> <b>` without `--is-ancestor` keys `merge-base-of.<a>.<b>`; `cat-file blob <oid>` keys `cat-file.<oid>`; `merge-file ... <o1> <o2> <o3>` keys `merge-file.<o1>.<o2>.<o3>`; `hash-object` with `-w` keys `hash-object-w.<final component of the -C path>.<path after -->`, so fixture keys are host-independent (`wt` or `consolidation`).
