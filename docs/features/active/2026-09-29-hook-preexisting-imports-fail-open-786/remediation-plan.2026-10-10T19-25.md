## 2. Per-row cause table (planning-time analysis; [P1-T2] to [P1-T6] confirm it on the host)

Mechanism A (drive-letter fixture). A fixture path beginning `C:` reaches a provider operation in the hook. On Linux no `C` drive exists, so `Join-Path` raises `DriveNotFoundException`, and the Pester mock proxies of `Get-Content` and `Get-ChildItem` cannot resolve the FileSystem provider's dynamic parameters (`-Raw`, `-File`) for that path, which surfaces as `A parameter cannot be found that matches parameter name 'Raw'` (or `'File'`). In the entry-point rows the error lands in the hook's outer `catch`, which writes stderr and exits 2. The repository already uses drive-free root-relative fixture paths with `Get-Content -Raw` hooks that pass the same Linux job: `tests/scripts/claude-hooks/enforce-prd-feature-before-planner.CheckpointFolder.Tests.ps1:34-35` against `.claude/hooks/enforce-prd-feature-before-planner.ps1:174`, and `tests/scripts/claude-hooks/enforce-feature-folder-order.Tests.ps1:357` against `.claude/hooks/enforce-feature-folder-order.ps1:96`.
