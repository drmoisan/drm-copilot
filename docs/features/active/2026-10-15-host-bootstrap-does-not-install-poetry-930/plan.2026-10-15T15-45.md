For a task that names `INLINE-STEP <catalogue-name>`, the executor (a) writes the wrapper `SCRATCH/issue-930/<task-id>.sh` with the Write tool as exactly two lines: line 1 is `cd "$(git rev-parse --show-toplevel)"` and line 2 is the catalogue entry for `<catalogue-name>` copied character for character from the `## Inline Command Catalogue` section (a single-line `pwsh -NoProfile -NonInteractive -Command '<body>'` call), and (b) runs `sh SCRATCH/issue-930/<task-id>.sh` from the worktree root. Line 1 makes relative paths resolve from the worktree root regardless of the caller's directory, and `pwsh` is the last command so the wrapper exit code is the `exit` code of the body. The wrapper IS the verbatim inline command; the evidence `Command:` field records line 2 of the wrapper. Every body is single-quote-free (strings use double quotes), so the single-quoted shell argument cannot be broken. If a wrapper prints neither the expected output lines nor a diagnostic that explains the failure, the task is recorded and the plan halts as BLOCKED; the executor does not substitute a `.ps1` file. An evidence `Output Summary:` quotes only the output lines named by the task's acceptance condition; console passthrough lines are not copied; a returned MCP summary string that contains an absolute path is quoted with the worktree-root prefix removed.
