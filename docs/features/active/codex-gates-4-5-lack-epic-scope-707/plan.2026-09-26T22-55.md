## 0. Rules binding on every task

1. **Evidence location and schema.** Every artifact is written under `docs/features/active/codex-gates-4-5-lack-epic-scope-707/evidence/<kind>/` with `<kind>` one of `baseline`, `regression-testing`, `qa-gates`, `other`. Every command-step artifact carries `Timestamp:` (format `yyyy-MM-ddTHH-mm`), `Command:`, `EXIT_CODE:`, and `Output Summary:`. An artifact whose gate is expected to exit non-zero also carries `ExpectedExitCode: 1`. `EXIT_CODE: SKIPPED` is never a passing outcome, and no task in this plan authorizes a skip.
2. **No host data.** No artifact, test, fixture, or document written by this plan contains an absolute filesystem path, a drive letter, a user-profile path, or the executing account name. Where a command prints such a value, the artifact records it with the worktree root replaced by `<WORKSPACE_ROOT>` and the session scratchpad by `<SCRATCHPAD>`. Tests use only the synthetic roots `/synthetic-worktrees/epic-coordinator`, `/synthetic-worktrees/epic-integration`, `/synthetic-worktrees/epic-other`, and `/outside/...`, which name no host. No test writes a `gitdir:` line without a space after the colon.
3. **Fresh process.** Every PowerShell toolchain run, Pester run, and cmdlet observation named in an acceptance condition (`Select-String`, `Get-Content`, `Get-FileHash`, `Copy-Item`, `ConvertFrom-Json`, `Import-PowerShellDataFile`) executes in a fresh PowerShell 7 process launched through the route [P0-T5] selects. Scripts live in the session scratchpad, contain only repository-relative paths, obtain the root with `$root = (Get-Location).Path`, and are launched with the worktree root as the working directory.
4. **No count is read from a PoshQC MCP result.** The MCP tools `mcp__drm-copilot__run_poshqc_format`, `mcp__drm-copilot__run_poshqc_analyze`, and `mcp__drm-copilot__run_poshqc_test` compose their summary before the child runs, carry no test output, and read the installed-extension settings, which may ignore new `CodeCoverage.Path` entries. They are run once in [P6-T9] as the spec-named supplementary check, and only their ok flag is recorded. Every count, percentage, or finding an acceptance condition reads comes from the self-hosted module functions `Invoke-PoshQCFormat`, `Invoke-PoshQCAnalyze`, and `Invoke-PoshQCTest` exported by `scripts/powershell/PoshQC/PoshQC.psd1`, or from the scoped runner R-SCOPED of section 5.
5. **Batch budget.** `.claude/hooks/enforce-powershell-batch-budget.ps1` caps Write/Edit of PowerShell files (`.ps1`, `.psm1`, `.psd1`) at three production and three test files per session. Each batch phase begins with a reset task that deletes each file whose name begins `powershell-batch-budget.` and ends `.json` in `.claude/state/` (gitignored runtime state, never staged) and appends an entry to `docs/features/active/codex-gates-4-5-lack-epic-scope-707/evidence/other/batch-budget-resets.md` naming the deleted files or `none present`. Section 6 fixes the file set of each batch.
6. **Mirrors are byte copies.** Every bundle or settings mirror is written with `Copy-Item -LiteralPath <source> -Destination <mirror> -Force` inside a scratchpad script launched through the [P0-T5] route, never with Write or Edit, so it consumes no budget slot and is byte-identical by construction. Each mirror task appends the copy commands and one SHA-256 pair per file to `docs/features/active/codex-gates-4-5-lack-epic-scope-707/evidence/other/mirror-log.md`. Parity is always computed against the files as they exist at execution time; no task asserts a pinned hash.
7. **Diff anchor.** No command uses `origin/main` as a git ref (CI checks out at depth 1, and a remote ref advances independently). Every `git diff` carries the explicit operand `<BASE_SHA>` (the value recorded as `BASE_SHA:` in `evidence/baseline/p0-base-ref.md`), and every name-listing diff is paired with a `git status --porcelain` observation in the same task. The literal `origin/main` appears in this plan only as a prohibited-token search operand required by AC-15.
8. **Porcelain scope.** After Phase 0, a clean-tree condition is stated as "lists no path outside `docs/features/active/codex-gates-4-5-lack-epic-scope-707/`, `.claude/state/`, `.claude/agent-memory/`, or `.codex/state/`". The three runtime-local prefixes hold gitignored hook state and agent memory that this plan never stages.
9. **Commit form.** Before staging, record `git status --porcelain -- docs/features/active/codex-gates-4-5-lack-epic-scope-707/evidence` in `docs/features/active/codex-gates-4-5-lack-epic-scope-707/evidence/other/commits.md`; every listed path must be an artifact named by a task of the current or an earlier phase, and any other path stops the commit. Commit tasks stage the named paths explicitly with `git add -- <paths>` (no `-A`, no `.`), write the message to a scratchpad file, and commit with `git commit -F <SCRATCHPAD>/<name>.txt -- <paths>` naming the same paths. The message ends with the attribution trailer lines required by the session's attribution instructions. No task pushes. After each commit the task appends the SHA and a `Porcelain (post-commit, pre-append):` observation to `docs/features/active/codex-gates-4-5-lack-epic-scope-707/evidence/other/commits.md`.
10. **Sibling files are never written.** No task writes a tracked file under `.claude/`; deleting gitignored runtime files under `.claude/state/` by rule 5, [P0-T10] and [P6-T7] is the only write under `.claude/`. No task writes any of the four copies of `enforce-orchestration-preimplementation-gate-helpers.ps1`, `.codex/hooks/enforce-orchestration-preimplementation-gate-modes.ps1`, `.codex/hooks/enforce-completion-consistency.ps1`, `.codex/hooks/enforce-completion-helpers.ps1`, their bundle copies, or `scripts/dev_tools/push_down_codex_and_agents_customizations.py`.
