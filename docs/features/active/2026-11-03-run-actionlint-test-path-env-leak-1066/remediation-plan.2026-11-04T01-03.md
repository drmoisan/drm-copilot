## Remediation Design Decisions

- RD1 (F1, `TARGET`). The file-scope `$scriptRoot` assignment and `TestHelpers.ps1` dot-source move into the Describe `BeforeAll`. Reason: file-scope code runs during Pester discovery, before any run-phase block, so a capture in `BeforeAll` would always see `Import-ScriptFunction` already defined and would never remove it. The Describe `BeforeAll` begins with two captures, `$script:describeHadImportScriptFunction` (whether `Function:\Import-ScriptFunction` exists, read through `$ExecutionContext.SessionState.InvokeProvider.Item`) and `$script:describeHadArchiveModule` (whether `Get-Module -Name Microsoft.PowerShell.Archive` returns a module). It then dot-sources `tests/scripts/powershell/Support/TestHelpers.ps1` through a path built with `[System.IO.Path]` methods from `$PSScriptRoot`, and the existing `$script:scriptPath` and `Import-ScriptFunction` lines follow unchanged. A new Describe-level `AfterAll` removes `Function:\Import-ScriptFunction` through `$ExecutionContext.SessionState.InvokeProvider.Item` when `$script:describeHadImportScriptFunction` is false, and calls `Remove-Module -Name Microsoft.PowerShell.Archive` when `$script:describeHadArchiveModule` is false and the module is loaded. The captures, the dot-source expression, and the `AfterAll` call no command in `MOCKED`. The DD1 `BeforeEach`/`AfterEach` pair is unchanged, and no `It` block changes.
- RD2 (F2, `GUARD` LASTEXITCODE testcase), primary form `p`. The third `It` is replaced by `It 'run-actionlint.Tests.ps1 leaves global LASTEXITCODE at the value set before it runs'`. It runs two nested invocations with the DD2 configuration. The control holds a sentinel container (its `BeforeAll` sets `$global:LASTEXITCODE` to the sentinel `41`, and it holds one passing `It`) and a probe container (one `It` that stores `$global:LASTEXITCODE` in a holder hashtable passed through `New-PesterContainer -Data`). The target holds the sentinel container, `TARGET`, and the probe container. Assertions: the control probe value is `41` (precondition, with a `-Because` text stating that the harness overwrote the value between containers), and the target probe value is `41`. Pre-fix `TARGET` leaves the value set by its last `Invoke-ActionlintCommand` test, so the assertion can fail; P1-T4 shows that it does. Fallback form `s` (applied only under P1-T5): the third `It` becomes `It 'run-actionlint.Tests.ps1 restores global LASTEXITCODE in a Describe-level AfterEach'`, which parses `TARGET` with `[System.Management.Automation.Language.Parser]::ParseFile` and fails unless every assignment to `$global:LASTEXITCODE` inside an `It` or a `Mock` script block has an enclosing `Describe` or `Context` that directly holds a `BeforeEach` reading `$global:LASTEXITCODE` and an `AfterEach` assigning it. Both forms keep `G` at 4.
- RD3 (F1 class in `GUARD`): IN. A fourth `It 'run-actionlint.Tests.ps1 leaves global functions and loaded modules as the nested harness leaves them'` compares the function names visible from the `It` (`Get-ChildItem -Path Function:`) and the loaded module names (`Get-Module`) before and after a nested `TARGET` run, takes that delta minus the delta of a nested control run, and asserts that the difference is empty, naming each entry in the `-Because` text. The guard's `AfterEach` also removes each function and module that its `BeforeEach` snapshot did not hold, so the guard leaks nothing when it fails. Reason for IN: the F1 leak was visible only to the scratch tool `SCRATCH/issue-1066-global-state.ps1`, which CI does not run, so without this testcase a regression of RD1 would go undetected. Cost: one testcase, and its fail-before is the pre-RD1 tree (P1-T3).
