## Verified Facts the Plan Relies On

- `pyproject.toml` line 116 is `addopts = "-ra --cov-report=lcov:artifacts/python/lcov.info"`. It carries an LCOV reporter only and no terminal reporter, so a coverage command that omits `--cov-report=term-missing` prints no table (rule G9).
- `pyproject.toml` line 120 is `source = ["src", "scripts/dev_tools"]` under `[tool.coverage.run]`. A bare `--cov` with no value measures those two sources. The repo-wide Python figure in this plan is therefore the figure over `src` and `scripts/dev_tools`.
- `[tool.coverage.run]` (lines 119 to 127) sets no `branch = true` entry, and the pytest `addopts` carries no `--cov-branch`. The configured run therefore measures statement coverage only: its terminal table prints `Stmts`, `Miss`, `Cover` and no branch columns. Branch data is obtained by adding the `--cov-branch` command-line flag in Run B (P1-T3). That flag is not a configuration change.
- The terminal `Cover` column of a branch run is one combined percentage. Separate line and branch percentages are therefore taken from the `totals` block of `coverage json` (P1-T4) and cross-checked against the `BRDA` records of the LCOV file (P1-T5).
