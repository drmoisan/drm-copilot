## Size Justification

The item spans more than sixty files across `.claude`, `.codex`, `.agents`, `.github`, `scripts/dev-tools`, and three bundle trees, plus four test languages with separate baseline and final gates (Pester, pytest, Jest, bats) and two required `origin/main` syncs, so it needs 43 tasks. The fifth revision adds P0-T8 (the process-reduction region inventory every ledger-bearing task reads) and P6-T7 (the lane statement and entry `0011`, which the README requires in one commit), because the ledger rule spans more than twenty files and its commit cannot be merged into a task that edits production code. The third revision added P1-T5, because the command-form normalizer and its matrix of prefix and launch forms (spec D25) would push `test-execution-policy.ps1` past the file-size tiers and its test file past a reviewable size. The fourth revision adds `Invoke-PesterSuite.ps1` inside P3-T1 (two PowerShell production files, within the batch budget) rather than as a new task. The caller sweep of the second revision added two Phase 5 tasks, because seven Python production files read launcher exit codes or output and no task may edit more than three. Tasks are grouped one per surface family; merging further would put more than three production PowerShell or Python files in one task (batch budget) or join gates whose evidence must stay separate.
