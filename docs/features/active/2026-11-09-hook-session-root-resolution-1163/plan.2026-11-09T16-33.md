- CI-only behavior: suites under `tests/scripts/claude-hooks` and `tests/scripts/codex-hooks` also run in `poshqc / PowerShell hook suites (Linux)` on `ubuntu-latest` with coverage disabled, so rows use POSIX roots, `Join-Path`, exact case, and no drive letters or backslash literals. - Evidence: branch hook changes are not exercised by isolated subagents until merge, so behavior is proven by Pester evidence only. Evidence is append-only with write-time UTC stamps, never back-dated, rewritten, or deleted, and records `SCRATCH` instead of any host path.

The plan therefore exceeds 20 tasks and 250 lines; mirror copies are grouped into one task per surface to keep it as compact as the scope allows.
