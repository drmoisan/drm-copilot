## Executive Summary

The branch fixes issue #995. Run checkpoints record `items[].worktree_path` relative to the main checkout, while every removal-gate matcher compared it to the absolute command target as a raw string. The parallel orchestrator also had no closing step. The branch adds a pure shared matcher module (`WorktreeRunRecordPath.psm1`) used by all six matcher-family sites and a `### Run Closing` procedure in the `parallel-orchestrate` skill and `parallel-orchestrator` agent.
