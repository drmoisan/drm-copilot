The remaining observations are Low or Info test and documentation items. The one blocking finding of this review is a coverage-artifact finding recorded in `policy-audit.2026-10-16T05-09.md` (PA-1); it does not identify a code defect.

## Detailed Notes

### Create side

- Token rule (`enforce-pr-author-skill.docs-only.ps1:139-144`): `Length -ge 2`, first character `-`, second not `-`, and `Substring(1).IndexOfAny(@('B','R'))` (ordinal, case-sensitive) matches spec Design item 1. Lowercase `-b`/`-r` are not matched. The check runs inside the existing loop before the `--base` count check and before any git call.
- E3 message (`:191`) names `--base <branch>`, `-B`, `-R`, `--repo`, the shorthand cluster, and `GH_REPO=` (AC-5).
- NUL guard: `Get-DocsOnlyDiffTextViolation` runs after the exit-code check and returns `DIFF_FAILED` for non-empty text without a trailing NUL; empty text still reaches `EMPTY_DIFF`.
- The unguarded dot-source of the helper directly after `param()` (`:44`) is covered by the guarded load of the docs-only file in the helpers file, per spec Design item 12.

### Merge side

- `Get-DocsOnlyMergeShapeViolation` runs before any process: positive number, one non-raw-scan segment, structural `gh pr merge`, no `VAR=` token, no single-dash token containing `R`, no `--repo`/`--repo=`, no `--auto`/`--auto=`. False denials (for example a `--body "x=y"` value) fall back to the standalone route, which is the fail-closed direction.
- `Get-DocsOnlyPullRequestTarget`: non-zero gh exit or non-object JSON denies `PR_UNRESOLVED`; base must match `^[A-Za-z0-9][A-Za-z0-9._/-]*$` without `..`; head must be 40 or 64 lowercase hex; a `--match-head-commit` value must equal the head (ordinal).
- M4 to M9: base ref resolved to a hex commit; head commit present locally and equal to `headRefOid`; three-dot diff from the resolved base commit; shared NUL and path classification.
- Gate placement: the Claude branch runs only after the standalone record fails and only when `Test-EpicMergeGateNoRecordingTarget` holds; the Codex branch runs only when both checkpoint texts are blank (OD-1).

### Tests

- Existing Claude suites that dot-source the gate gained the two baseline seam mocks in their top-level `BeforeAll`; no existing assertion line changed (diff shows +2 lines per suite).
