## Size Justification

The plan has 33 tasks, above the 20-task guideline, because one plan carries the whole child (OQ-8): five generator surfaces with seven new PowerShell production files, the converter redirection in two parity implementations (H3), the matrix upkeep, the repository gate and the brief update, plus the mandated Phase 0 gate and baselines, six phase gates and the final QA phase. Each surface is a module task, a source-authoring task and one generator-run task, which is the smallest set whose outcomes are separately verifiable; splitting the child into several items would repeat the Phase 0 gate and baselines in each.
