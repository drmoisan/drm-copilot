**Evidence filename rule:** Every new evidence artifact is named `<name>.<timestamp>.md`, where the stamp is the UTC time read immediately before the write with `pwsh -NoProfile -Command "Get-Date -AsUTC -Format yyyy-MM-ddTHH-mm"`. If the worktree isolation guard refuses that command, the executor derives the stamp from `TZ=UTC git var GIT_COMMITTER_IDENT` and records the derivation in the artifact. A task that consumes an artifact selects the lexicographically greatest file matching `<name>.*.md`. Every new evidence artifact carries `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`.

**EXIT_CODE truthfulness rule:** `EXIT_CODE:` is a real process exit code of a command the executor ran. For an action that was not a command (a Read tool read, a Write or Edit tool write), the executor does not invent an exit code. The executor may state `EXIT_CODE: 0` only for a file-write action observed to succeed (the file exists afterwards), and must say in a companion line that the value applies to the file-write action only.

**Acceptance-method note:** The executor has Grep, Glob, Read, Edit, Write and Bash limited to git, pwsh, poetry and npx. Token checks use the Grep tool on the named file, with `output_mode: count` or `content`. Path-scope checks use `git diff --name-only origin/main...HEAD` (committed paths only) paired with `git status --porcelain -uall` (uncommitted and untracked paths); each alone is blind to the other state. Counts that would need a pipe are read from the printed lines.
