## Planning Decisions

- D1. The opt-in command's coverage-measured source is `scripts/ci/Set-CiRequiredChecks.ps1` (inside the `config/poshqc-coverage.json` root `scripts`); `CIB/Set-CiRequiredChecks.ps1` is its byte-identical bundle copy, delivered to `.github/drm-copilot/Set-CiRequiredChecks.ps1`. Its logic is in functions; the script body outside functions is one call to `Invoke-SetCiRequiredChecks`.
- D2. Copy-mode files are byte-identical bundle copies `CIB/workflows/harness-<stem>.yml` of `.github/workflows/harness-<stem>.yml` (stems `python`, `powershell`, `typescript`, `dotnet`), written to `.github/workflows/drm-copilot-<stem>.yml`. `harness-powershell.yml` takes a boolean input `poshqc` (default true: load PoshQC from `job.workflow_repository` at `job.workflow_sha`; false: run Pester 6 directly); the copy-mode caller passes `poshqc: false`.
- D3. CI files ride #1029's `shared` layer as root-file pairs: caller (source `CIB/caller/drm-copilot-ci.template.yml`, text produced by the layer rewrite), data file `CIB/ci-required-checks.json`, command `CIB/Set-CiRequiredChecks.ps1`, and copy-mode copies. Manifest `pack` is `core` for caller, data file and command, and the language pack name for a copy. Every CI path is in the layer's new optional `unmanagedProtectedPaths`, for which the pipeline classifies with `overwriteUnmanaged` false.
- D4. Pack-to-job mapping: `python`, `powershell`, `typescript` map to their stems; `csharp-modern`/`csharp-legacy` map to `dotnet` with `variant: modern`/`legacy`; Codex and Copilot `csharp` map through the record's `csharp_variant`, `modern` when absent. Copy inference counts only the four `drm-copilot-<stem>.yml` paths, never `drm-copilot-ci.yml`.
