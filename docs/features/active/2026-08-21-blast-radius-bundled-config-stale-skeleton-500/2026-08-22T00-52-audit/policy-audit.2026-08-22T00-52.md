## 8. Gaps and Exceptions

### Identified Gaps

1. **CR-1, Major. Class 2 does not detect self-hosted-side growth.** `test_class_two_bundled_shared_surfaces_are_the_portable_set` compares the bundled set against the hand-declared `PORTABLE_SHARED_SURFACES` constant and against a subset relation. AC9 and AC10 name a file that does not carry the gate.** Both criteria name `tests/scripts/dev_tools/test_blast_radius_config.py` and cite `poetry run pytest tests/scripts/dev_tools/test_blast_radius_config.py` as the verification. 4. **CR-4, Minor. The reviewer's first reproduction produced 979 and 954 edges; adding `spec_text` produced the recorded 1199 and 1182 exactly.

6. **CR-6, Minor. The PowerShell Class 1 comparison uses a pipeline `ConvertTo-Json`.** The piped form unrolls a collection, so a single-element list and a bare scalar serialize identically and an empty list serializes the same as an absent key.
7. **Pre-existing. The architecture-boundary stage is not runnable.** No `.dependency-cruiser.cjs` and no `depcruise` script exist anywhere in the repository. Recorded in section 2.5.
8. **Pre-existing. `$schema` is absent from both truth tables.** Recorded in section 3D.
