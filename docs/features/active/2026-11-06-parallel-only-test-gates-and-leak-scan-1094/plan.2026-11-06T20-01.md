## Execution Rules

Out of scope` and that bullet's words between `static` and the comma, matched case-insensitively. Plans and evidence refer to them by this name.

These rules apply to every task:

- **Commit and push.** Each task ends with one commit and one push of that commit to `feature/parallel-only-test-gates-and-leak-scan-1094`. The executor stages only the paths the task names, with worktree git and no `git -C`. Evidence the task writes is staged with it. `.claude/agent-memory` is never staged.
- **`testResults.xml`.** This tracked file is rewritten by Pester runs. Restore it with `git checkout -- testResults.xml` before staging.
- **Poetry.** Do not run an unqualified `poetry install` from the item worktree: the shared `.venv` would be repointed at it.
- **Parallel gates only (owner directive; P1-T1 and P1-T2 put this in the skill text in this item).** The Pester gate is one `Invoke-PoshQCParallelTest` run. The pytest gate is one `pytest -n auto` run. A suite is re-run only after a fix. No task requires a single-process, seeded-shuffle, reversed-order, or comparison run. A focused run of one test file to debug a specific failure is debugging only: it is never a gate, an acceptance condition, or evidence, and it is not recorded.
- **Test proof.** A task that adds or changes a test is accepted on the named test's presence and content. Its pass result is proved once, by the gates in Phase 2.
- **Gate failures.** No condition waives a failure. A failure is fixed and the failed gate is re-run. A failure that traces to the live gitignored `artifacts/orchestration/orchestrator-state.json` in a suite outside this plan's file set stops the executor, which returns to the orchestrator and names the test and the state it read.
- **Text mirrors.** A task that edits a mirrored text surface edits every copy it names and its contract test in the same task, so no mirror test sits red between tasks.
- **Evidence.** Every command-step artifact carries `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`. The recorded `EXIT_CODE:` must go non-zero when the task's asserted value fails. Filename stamps are the write time in UTC. Evidence prose never uses the tokens that P2-T5 scans for, including where it records that such a run was not performed.
- **Scope.** Do not edit `.claude/rules/`, `.github/instructions/`, their bundle copies, `.agents/skills/powershell/`, `.agents/skills/python/`, the other policy mirrors `.agents/skills/csharp/`, `.agents/skills/typescript/`, and `.agents/skills/quality-tiers/`, `.claude/agents/epic-orchestrator.md`, `.claude/skills/epic-orchestrate/SKILL.md`, `scripts/dev_tools/validate_policy_audit_artifact.py`, `extensions/drm-copilot/src/lib/validate/policy-audit-artifact.ts`, `.github/workflows/`, `scripts/powershell/PoshQC/`, `.vscode/tasks.json`, the Python tools in spec `### 2.
