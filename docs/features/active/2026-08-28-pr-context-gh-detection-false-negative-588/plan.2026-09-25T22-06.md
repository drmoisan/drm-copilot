## Named tests introduced by this plan

TypeScript, `extensions/drm-copilot/test/lib/executable-resolver.test.ts`:

- `describe("resolveExecutableOnPath")`
  - R1 `returns the gh.exe candidate for a win32 PATH and PATHEXT`: `platform: "win32"`, `pathValue: "\\tools\\bin;\\apps\\GitHub CLI"`, `pathExtValue: ".COM;.EXE;.BAT;.CMD"`, `exists` a case-insensitive membership test over `{"\\apps\\github cli\\gh.exe"}`, `name: "gh"`; expects `"\\apps\\GitHub CLI\\gh.EXE"` (PATHEXT casing is preserved in the candidate).
  - R2 `matches a lower-case PATHEXT entry against an existing gh.exe`: `platform: "win32"`, `pathExtValue: ".exe"`, `pathValue: "\\apps\\gh"`, `exists` over `{"\\apps\\gh\\gh.exe"}`; expects `"\\apps\\gh\\gh.exe"`.
  - R3 `tries a name that already ends in a PATHEXT extension as-is`: `platform: "win32"`, `name: "gh.EXE"`, `pathExtValue: ".exe;.cmd"`, `pathValue: "\\apps\\gh"`, case-insensitive `exists` over `{"\\apps\\gh\\gh.exe"}`; expects `"\\apps\\gh\\gh.EXE"` and the first `exists` call argument is `"\\apps\\gh\\gh.EXE"`.
  - R4 `returns the posix candidate from the first PATH directory that contains the name`: `platform: "linux"`, `pathValue: "/usr/local/bin:/opt/gh-bin"`, `exists` over `{"/opt/gh-bin/gh"}`; expects `"/opt/gh-bin/gh"`.
  - R5 `ignores PATHEXT on non-win32 platforms`: `platform: "linux"`, `pathExtValue: ".EXE"`, `pathValue: "/opt/gh-bin"`, `exists` over `{"/opt/gh-bin/gh", "/opt/gh-bin/gh.EXE"}`; expects `"/opt/gh-bin/gh"` and the recorded `exists` calls equal `["/opt/gh-bin/gh"]`.
  - R6 `returns the earlier directory's match when several directories contain the name`: `platform: "linux"`, `pathValue: "/first:/second"`, `exists` over `{"/first/gh", "/second/gh"}`; expects `"/first/gh"`.
  - R7 `returns undefined when no candidate exists`: `platform: "linux"`, `pathValue: "/opt/gh-bin"`, `exists` always returns `false`; expects `undefined`.
  - R8 `returns undefined for an undefined PATH`: `platform: "linux"`, `pathValue: undefined`; expects `undefined` and `exists` is never called.
  - R9 `returns undefined for an empty PATH`: `platform: "linux"`, `pathValue: ""`; expects `undefined` and `exists` is never called.
  - R10 `skips empty PATH entries`: `platform: "linux"`, `pathValue: "::/opt/gh-bin:"`; the recorded `exists` calls equal `["/opt/gh-bin/gh"]` and the result is `"/opt/gh-bin/gh"`.
  - R11 `falls back to the default PATHEXT list when PATHEXT is unset`: `platform: "win32"`, `pathExtValue: undefined`, `pathValue: "\\apps\\gh"`, case-insensitive `exists` over `{"\\apps\\gh\\gh.bat"}`; expects `"\\apps\\gh\\gh.BAT"` and recorded calls `["\\apps\\gh\\gh.COM", "\\apps\\gh\\gh.EXE", "\\apps\\gh\\gh.BAT"]`.
- `describe("defaultWhichGh")` (file-level `jest.mock("node:fs")` with `existsSync: jest.fn()`; `process.env.PATH`, `process.env.PATHEXT`, and `process.platform` set per test and restored in `afterEach`)
  - D1 `resolves gh from process PATH, PATHEXT, and platform through fs.existsSync`: PATH `/opt/gh-bin`, PATHEXT deleted, platform `linux`, `existsSync` true only for `/opt/gh-bin/gh`; expects `"/opt/gh-bin/gh"` and `existsSync` called with `"/opt/gh-bin/gh"`.
  - D2 `returns undefined when fs.existsSync reports no candidate`.
