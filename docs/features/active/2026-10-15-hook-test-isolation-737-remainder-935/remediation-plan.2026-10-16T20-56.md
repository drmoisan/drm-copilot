- Pester 5 scoping (read in the Pester 5.9.0 module source, `Pester.psm1`; host paths are not recorded): in discovery, `Invoke-File` dot-sources each container file into the caller's session state, so a `$script:` variable written during discovery lands in a scope shared by the discovery of every container; in the run phase, `Run-Test` runs each container through `Invoke-InNewScriptScope`, which pushes a fresh script scope per container, so run-phase `$script:` state is per container and a value written in BeforeDiscovery is not visible to BeforeAll through `$script:`. - Pester 5 path order (same source): `Find-File` resolves `Run.Path` entries in the given order and removes duplicates with a set that keeps the first occurrence; it does not sort. A direct run therefore executes containers in the `-Path` order, which P4-T12 verifies by comparing its planned and observed container orders. `run_poshqc_test` sorts its folders and files before calling Pester (`P5-T4`).
- Closure order is load-bearing: `Get-EpicStateSeamRequirement` keeps the first census record of each group (`$group.Group[0]`, which supplies the requirement `Class`), and `Get-EpicStateProbeSeam` reports seams in census order. A per-suite closure built as a union of separately cached per-hook closures would reorder files whenever a suite names more than one hook, because the current walk is one breadth-first walk over all hook seeds. PERF-1 therefore memoizes per file (each file's text, and the paths its literals resolve to) and keeps the single breadth-first walk over those cached nodes: each hook file and each of its transitive dependencies is read and resolved once per reader instance, which is the reuse the operator asked for, and the closure order is unchanged. This is a recorded design refinement of the operator's "union of cached hook closures" wording, made to meet the operator's constraint that no row changes what it asserts.
- The walk resolves each `.ps1` or `.psm1` literal to the first candidate for which the reader returns text: a candidate already in the closure was itself read successfully, so the current `if ($loaded.Contains($candidate)) { break }` check selects the same candidate as the existence check, and the walk enqueues it only when it is not yet in the closure. The memoized successor list (first existing candidate per literal) plus the same not-yet-loaded check reproduces the current closure and its order.


It prints one line per suite file name (the text of the `classname` attribute after its last character that is not a letter, digit, `.`, `_` or `-`; no host path) with the number of its testcases and the number that carry `status="Passed"` and close on the same line (no `failure`, `error` or `skipped` child). function Get-EpicStateMemoSourceText {
```
    <#
        Pure over the injected reader: the reader's text for one path, or $null when it returns

function Get-EpicStateClosureSuccessor {
    <#
        Pure over the injected reader: the paths that the .ps1 and .psm1 string literals of one
        closure file resolve to, in literal order; each is the first candidate (resolved beside the
        file, beside the file by leaf, then in each library directory) for which the reader returns
        text. Memoized per reader instance, path and library directories (issue #935, PERF).
    #>
    [CmdletBinding()]
    [OutputType([string])]
    param(
        [Parameter(Mandatory)] [string] $Path,
        [Parameter(Mandatory)] [scriptblock] $ReadSource,
        [string[]] $LibraryDirectory = @()
    )
    $key = [System.Tuple[object, string]]::new($ReadSource, 'next' + [char]0 + $Path + [char]0 + ($LibraryDirectory -join [char]0))
    if (-not $script:EpicStateClosureNodeCache.ContainsKey($key)) {
        $text = Get-EpicStateMemoSourceText -Path $Path -ReadSource $ReadSource
        $folder = if ($Path.Contains('/')) { $Path.Substring(0, $Path.LastIndexOf('/')) } else { '' }
        $next = [System.Collections.Generic.List[string]]::new()
        $literals = if ($null -eq $text) { @() } else { (Get-EpicStateParsedSource -Text $text).Literal }
        foreach ($literal in $literals) {
            if ($literal -notmatch '\.psm?1$' -or $literal.Contains('*')) { continue }

                if ($null -ne (Get-EpicStateMemoSourceText -Path $candidate -ReadSource $ReadSource)) {
                    $next.Add($candidate)
                    break
                }
            }
        }
        $script:EpicStateClosureNodeCache[$key] = [string[]]$next.ToArray()
    }
```
