- **F2 design.** `Get-OrchestrationGateCommandOperandPath` keeps every path it returns today (the `-C` values in `GlobalOptions` and the absolute `Operands` of each `Structural` match) and adds the absolute tokens of a subcommand-aware walk. For each `Structural` match whose `Segment.ArgumentInjected` is not set, the walk reads `Segment.Tokens` from `OperandIndex` using an option model held inside the function body:
  - value-taking options, `commit`: `-m`, `--message`, `-F`, `--file`, `--author`, `--date`, `-C`, `--reuse-message`, `-c`, `--reedit-message`, `-t`, `--template`, `--fixup`, `--squash`, `--trailer`, `--pathspec-from-file`; `add`: `--pathspec-from-file`, `--chmod`;
  - standalone flags, `commit`: `-a`, `--all`, `--amend`, `--no-edit`, `--no-verify`, `-n`, `-s`, `--signoff`, `-q`, `--quiet`, `-v`, `--verbose`, `--allow-empty`, `-o`, `--only`, `-i`, `--include`, `--pathspec-file-nul`; `add`: `-A`, `--all`, `-u`, `--update`, `-f`, `--force`, `-N`, `--intent-to-add`, `-n`, `--dry-run`, `-v`, `--verbose`, `--pathspec-file-nul`.
  - A value option written as its own token consumes the next token; written inline (`--message=msg`) or attached to a short name (`-mmsg`: one leading dash, longer than two characters, first two characters a short value option) it consumes only itself. A standalone flag consumes itself. `--` makes every later token an operand. A redirection operator and its target are skipped as `Get-CommandLineInvocationOperand` skips them. Any other dash token, including a clustered short-flag token such as `-am`, stops the walk (the current conservative result). A collected token is a candidate only when it passes `Test-CommandLineTokenLiteral` and the existing absolute-path test. The `commit` options `-C` and `-c` are reuse-message options here; the git global `-C` before the subcommand is still read from `GlobalOptions` only.
