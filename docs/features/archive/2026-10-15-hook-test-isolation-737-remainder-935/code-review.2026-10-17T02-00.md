## Executive Summary

- Memo design (PERF-1): the three new memos are suite-local in the run phase and reset at every dot-source of the Discovery helper. Keys are correct for the inputs they depend on: census by path and full text (ordinal), closure nodes by reader instance plus path (and library directories for successors), reader by repository root. No consumer mutates a cached census record (`Get-EpicStateSeamRequirement` groups and reads; `Get-EpicStateSuiteCensusRow` reads `Name`).
- Behaviour preservation: `Get-EpicStateLoadedSourceClosure` keeps its breadth-first order and result. The removed check "`if ($loaded.Contains($candidate)) { break }`" is subsumed: a loaded path always has non-null text from the same reader, so the first candidate with text is the first candidate the old loop would stop at; the new loop enqueues it only when not loaded, as before. `Get-EpicStateVariableHookLoad` element emission writes the same elements (all callers wrap the call in `@(...)`). The row-name hash of the 365 pre-existing Discovery rows is unchanged (`r4-perf-timing-after.2026-10-17T01-09.md`).
- TEST-1: each of the six rows places the Mock under a `StatementBlockAst` whose parent is the named construct, so `Get-EpicStateIsolationDirectCommand` calls `Test-EpicStateIsolationConditionalAncestor` on it; a regression in any of those branches would make the row fail.
- CR-F4: the balanced pattern uses two `(?<var>...)` groups in alternation, which .NET permits; the fail-before record shows the new negative row failing on the optional-brace pattern. The braced alternative has no positive row (TEST-2).
- The 12 `[CmdletBinding()]` additions match the CR-F2 list; no caller passes extra positional arguments (the full suites pass).
- Two behaviour-adjacent defects in the new code: the AC-5b `Should -Not -Throw` is vacuous after PERF-3 (CR-G1), and the `-Seam` path of `Get-EpicStateProbeFinding` skips the error guard (CR-G2). One pre-existing defect now sits under the new memo contract: the parse memo uses case-insensitive keys (CR-G3).
