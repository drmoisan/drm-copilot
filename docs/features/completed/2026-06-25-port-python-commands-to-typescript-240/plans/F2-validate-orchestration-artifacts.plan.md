All evidence artifacts MUST be written under the canonical feature evidence scheme `<FEATURE>/evidence/<kind>/` where `<FEATURE>` = `docs/features/active/2026-06-25-port-python-commands-to-typescript-240`. Sub-paths used by this plan:

- `evidence/regression-testing/` — port-parity / behavior-parity capture and any fail-before evidence.

If any instruction supplies a non-canonical path, substitute the canonical path and record `EVIDENCE_LOCATION_OVERRIDE_REJECTED: <supplied> replaced with <canonical>`.
