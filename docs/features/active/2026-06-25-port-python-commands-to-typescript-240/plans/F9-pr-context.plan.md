## Scope and Constraints

This feature ports the full PR-context collection cluster (`pr_context/`) to in-process TypeScript and wires `RepoAutomationService.collectPrContext()` to call it directly instead of spawning `resources/templates/collect_pr_context.py`.

Hard constraints (enforced by every code task):
- No production, test, or reusable-script file may exceed 500 lines. `github.py` (549) and `collector.py` (619) are split as instructed; split any TS file further if it would exceed 500 lines.
- New `src/lib/pr-context/**` files: line coverage >= 85%, branch coverage >= 75%.
- Tests are hermetic: inject `FileSystem` (`src/lib/file-system.ts`) and `CommandRunner` (`src/lib/subprocess-runner.ts`); no real `git`/`gh`, no real filesystem, no temp files.
- Reuse F1 `src/lib/file-system.ts` and `src/lib/subprocess-runner.ts`. Do not re-port them.
- ES modules, strong typing, no `any`; kebab-case filenames; AAA test structure; Jest (`@jest/globals`, `jest.fn()`, `jest.mock`).
- Do NOT modify `command-runtime.ts`, the `"python"` runtime branch, or any Python under `scripts/dev_tools/**` or `resources/**/*.py` (removal is F11).
- `extensions/drm-copilot/src/repo-automation-service.ts` must remain <= 500 lines. The `collectPrContext()` body delegates to a new `pr-context-service-call.ts` helper.

### FileSystem capability note (decision recorded for the executor)

`pr_context/feature_docs.py` and `verification_evidence.py` require directory iteration and existence predicates (`Path.exists`, `Path.is_dir`, `Path.iterdir`, `Path.glob`) that the shared F1 `FileSystem` interface does not yet expose (it has `glob`, `isFile`, `readTextFile`, `writeTextFile`, `ensureDir`). The shared interface is extended additively in Phase 0/Phase 2 (new methods `exists`, `isDirectory`, `listDirectory`) with matching `RealFileSystem` implementations; existing F1 consumers and tests are unaffected because the additions are new optional-free methods on the interface and concrete class. No existing method signature changes. This keeps the pr-context port hermetic without re-porting `file-system.ts`.
