## Design Notes and Premise Corrections

- **Reader.** `Read-PreToolUseDispatchStandardInput` (Claude) and `Read-CodexPreToolUseDispatchStandardInput` (Codex) take `[scriptblock] $OpenStream = { [Console]::OpenStandardInput() }`, build `[System.IO.StreamReader]::new($stream, [System.Text.UTF8Encoding]::new($false, $false), $true)` (the third argument is BOM detection), return `ReadToEnd()`, and dispose the reader in `finally`, which also disposes the stream. The two function bodies, including their comment-based help, are byte-equal; the help therefore never names its own function.
- **Script-tail tests (changed existing behavior).** The two existing rows `denies a payload without a tool name through the registry beside the script when run in process` feed the payload through `[Console]::SetIn`, which the new byte reader bypasses (it opens the process handle). Disposition: updated. The Claude row mocks `Read-ClaudeHookRawPayload` to return the no-tool-name payload and asserts one call whose `ReadStandardInput` script block text names `Read-PreToolUseDispatchStandardInput`; the Codex row mocks `Read-CodexPreToolUseDispatchStandardInput` and asserts one call. Both rows keep their existing exit-code, emitted-count, and `HOOK_DISPATCH_BLOCKED:` reason assertions, so AC-15 holds; only the arrange step changes and one call assertion is added. Neither row calls `[Console]::SetIn` afterwards, so no row reads the real process stdin.
- **AC-10 premise.** The stop hook validates ledger lines through `Select-OwnerDirectivePassDown`, which applies rules B2-B8 through `Get-OrchestratorStateOwnerDirectiveValidEntry` (same module as `Get-OrchestratorStateOwnerDirectiveError`); `Get-OrchestratorOutputOwnerPassDownLedgerError` filters those errors. AC-10 rows therefore assert the stop-hook result, which exercises the actual ledger path.
- **Existing tests asserting changed dispatcher behavior, with disposition.** `tests/scripts/claude-hooks/invoke-pretooluse-dispatch.Tests.ps1`: `reads the payload once through Read-ClaudeHookRawPayload` unchanged (mocks the function; the new default still calls it once); `emits the combined decision as compact JSON followed by exit code 0` unchanged (ASCII reason, byte-identical under `EscapeNonAscii`); trace rows unchanged (parse the line); script-tail row updated (above). `tests/scripts/codex-hooks/invoke-pretooluse-dispatch.Tests.ps1`: `reads the payload once`, `uses no environment fallback when stdin is empty`, `emits the combined decision as JSON followed by exit code 0`, trace rows unchanged (seams injected, ASCII); script-tail row updated. `PreToolUseDispatch.Parity.Tests.ps1` process rows unchanged (ASCII corpus; trace and stdout parsed with `ConvertFrom-Json`). `PreToolUsePayload.Contract.Tests.ps1` unchanged (dispatcher text keeps `Read-ClaudeHookRawPayload`). `hook-dependency-guard-completeness.Tests.ps1` with `HookGuardShape.Helpers.ps1` rule S1 and S6 unchanged (only the existing tail emit gains a parameter; no statement is inserted; no new dot-source edge). `hook-dependency-failure.Claude.Tests.ps1` and `hook-dependency-failure.Codex.Tests.ps1` unchanged (ASCII `HOOK_DISPATCH_BLOCKED:` reason). `HookPayload.Tests.ps1` row `defaults the two stdin seams to the console redirect probe and the console reader` unchanged (module not modified). `codex-pretooluse-integration.Tests.ps1`, `codex-bundle-hook-probe.Tests.ps1`, `claude-settings.Tests.ps1`, `HookProcessCost.Tests.ps1`, `test-execution-policy.Registration.Tests.ps1`, `DiscoveryCapability.Tests.ps1`, and `test_codex_core_manifest_closure.py` unchanged (registration and path text only).
