## Gate Under Repair

For each matrix manifest `.`, `extensions/drm-copilot`, and `packages/mcp-server`, the job runs `npm ci` (lockfile/manifest sync check) and then `npm audit --audit-level=moderate` in the manifest directory. A manifest passes when both commands exit 0. This plan asserts both commands, in that order, in each manifest.

## Override Pattern

Each of the three `package.json` files already carries a top-level `overrides` object whose entries are a bare package name mapped to a caret range at the first patched version (for example `hono` and `@hono/node-server` in all three files). `deepmerge` has no entry. The narrowest permitted change is therefore: raise the caret floor of an existing entry to the first patched version that `npm audit` reports, or add one top-level `"<package>": "^<first patched version>"` entry in the same object. Nested override objects, exact pins, and `--force` are not used.
