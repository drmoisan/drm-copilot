## Merge-Form Decisions Under the Key

Rule: when the text could be a merge and the structural reader cannot bind it to one pull-request number, deny with `REVIEW_GATE_HEAD_UNRESOLVED` before any process. A bound command then goes through the existing guard, so a passing review at a current head is still required. "Disclosed" rows are stated in the honest disclosure, and a row pins that the result is an allow. The row names are the `Name` values of [P1-T1].

| Form | Decision | Row |
|---|---|---|
| `if`/`then`, `while`, `for`, `case` | denied | `wrapper-if-then`, `wrapper-while`, `wrapper-for`, `wrapper-case` |
| `exec`, `!`, `time`, `env`, `command`, `builtin` | denied | `wrapper-exec`, `wrapper-bang`, `wrapper-time`, `wrapper-env`, `wrapper-command`, `wrapper-builtin` |
| subshell, brace group, `$( )`, backticks | denied | `wrapper-subshell`, `wrapper-brace-group`, `wrapper-dollar-substitution`, `wrapper-backtick-substitution` |
| `eval`, `sh -c`, `bash -c`, `pwsh -c`, `xargs` | denied | `wrapper-eval`, `wrapper-sh-c`, `wrapper-bash-c`, `wrapper-pwsh-c`, `wrapper-xargs` |
| leading backslash; `cd` prefix | denied | `wrapper-leading-backslash`, `wrapper-cd-prefix` |
| quoted `"gh"` or quoted subcommand; line continuation | bound: the shell reads one plain merge, so the guard decides | `quoted-token-review-passed` allow; `quoted-token-review-pending`, `quoted-word-review-pending`, `line-continuation-review-pending` each `REVIEW_GATE_NOT_PASSED` |
| backslash inside a word; variable or substituted subcommand | denied | `split-backslash-word`, `split-variable-subcommand`, `split-substituted-subcommand` |
| REST `pulls/<n>/merge`, literal or variable number; `curl` to the same path | denied | `api-rest-merge`, `api-rest-merge-variable-number`, `api-curl-rest-merge` |

| `gh pr merge --auto`, `--admin`, `-R`, `--repo` | denied | `flag-auto`, `flag-admin`, `flag-repo-short`, `flag-repo-long` |
| more than one invocation: `;`, `&&`, `\|\|`, pipe, `&`, newline; bare second merge; any leading command | denied | `chain-semicolon`, `chain-and`, `chain-or`, `chain-pipe`, `chain-background`, `chain-newline`, `chain-second-bare`, `chain-push-then-merge` |

| script file; encoded or run-time composed text; alias or function from an earlier call; endpoint in a variable | disclosed | `disclosed-script-file`, `disclosed-encoded-payload` |

| PowerShell tool, `mcp__*` tools, web UI; Codex `shell_command` | disclosed: see below | none, because no hook runs |
