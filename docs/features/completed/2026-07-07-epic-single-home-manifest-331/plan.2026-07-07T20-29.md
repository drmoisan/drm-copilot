## Plan Invariants (apply to every phase)

- **Backward compatibility is a hard requirement.** All new logic is additive and key-gated. On
  legacy (folder-basename-keyed, two-tree) fixtures, `scripts/dev_tools/epic_wave_computation.py`
  and `scripts/dev_tools/validate_epic_orchestrator_state.py` must produce byte-identical output.
  Legacy fixtures/tests are never modified; new fixtures are added alongside.
- **Two parity trees change together.** Every runtime edit in the TypeScript authoritative tree
  (`extensions/drm-copilot/src/lib/new-active-feature-folder/{flow,io,docs}.ts`,
  `extensions/drm-copilot/src/lib/validate/epic-orchestrator-state-core.ts`) has a byte-identical
  behavioral counterpart in the Python co-authoritative tree
  (`scripts/dev_tools/new_active_feature_folder_{flow,io,docs}.py`,
  `scripts/dev_tools/validate_epic_orchestrator_state.py`). Error strings asserted identical stay
  identical.
- **Bundled mirror parity.** Every `.claude/**` runtime edit is mirrored byte-identically into
  `extensions/drm-copilot/resources/claude-customizations/.claude/**`.
- **mcp-server template copy is a build artifact.** `packages/mcp-server/resources/feature-templates/epic/*`
  is regenerated by `packages/mcp-server/prepack.cjs`; it is not hand-edited.
- **Out of scope (do not implement):** the epic-status hand-edit guard and migration of existing
  epics (including TaskMaster epic #260). Only the migration-deferral documentation task (P4-T9)
  is in scope.
- **Toolchain order (restart on any failure or auto-fix):** Python `poetry run black .` →
  `poetry run ruff check .` → `poetry run pyright` →
  `poetry run pytest --cov --cov-branch --cov-report=term-missing`; TypeScript (from
  `extensions/drm-copilot`) `npm run format` → `npm run lint` → `npm run typecheck` →
  `npm run test` (coverage `npm run test:coverage`).
- **Coverage gates (uniform T1–T4):** line coverage ≥ 85%, branch coverage ≥ 75%, no regression on
  changed lines.
- **Evidence root (non-overridable):** all evidence artifacts are written under
  `docs/features/active/2026-07-07-epic-single-home-manifest-331/evidence/<kind>/`. Writing to
  `artifacts/baselines/`, `artifacts/qa/`, `artifacts/coverage/`, or any other non-canonical path is
  prohibited. Timestamp format `yyyy-MM-ddTHH-mm`.
