- **JRP (JUnit Reduction Procedure)** applied to a JUnit file `J` (PowerShell; in executor-owned tasks it runs through the Tool route, in the same script as the run it reduces or in a separate `issue-953-<task id>-<n>.sh`):
  1. `[xml]$j = Get-Content -Raw -LiteralPath J`.
  2. Totals: attributes `tests`, `failures`, `errors` of the `testsuites` root element, read as integers.
  3. A `testcase` is failed when it has a `failure` or `error` child; skipped when it has a `skipped` child; passed otherwise.
  4. Token check for token `K`: `$hits = @($j.SelectNodes("//testcase[contains(@name, 'K')]"))`. PASS if and only if `$hits.Count -ge 1` and every hit is passed. Zero hits is FAIL.
  5. Failure check for token `K` (fail-before only): PASS if and only if `$hits.Count -ge 1` and every hit is failed; the failure message text (`failure/@message`) is recorded.
- **CRP (Coverage Reduction Procedure)** applied to a CoverageGutters (JaCoCo-structured) file `X` (PowerShell; in executor-owned tasks it runs through the Tool route):
  1. `[xml]$x = Get-Content -Raw -LiteralPath X`.
  2. Aggregate: `$agg = @($x.report.counter | Where-Object { $_.type -eq 'LINE' })`; require `$agg.Count -eq 1`, else FAIL. `LINE_COVERED = [int]$agg[0].covered`, `LINE_MISSED = [int]$agg[0].missed`, `LINE_TOTAL = LINE_COVERED + LINE_MISSED`, `LINE_PERCENT = [math]::Round(100.0 * LINE_COVERED / LINE_TOTAL, 2)`.
  3. Root prefix: `$anchor = @($x.report.package | Where-Object { ($_.name -replace '[\\]', '/') -like '*/scripts/powershell/PoshQC' -and @($_.sourcefile | Where-Object { $_.name -ceq 'PoshQC.Testing.psm1' }).Count -eq 1 })`; require `$anchor.Count -eq 1`. `ROOTP` = the normalized anchor name with the trailing `/scripts/powershell/PoshQC` removed. CoverageGutters records absolute directory paths, so this derives the run's workspace root from the report itself.
  4. Per-file map: for every `package` P and every `sourcefile` F under it, the normalized package name must start with `ROOTP + '/'` (case-insensitive), else FAIL. Key = (normalized package name minus `ROOTP + '/'`) + `/` + `F.name`, lowercased. Value = the integers `covered` and `missed` of the single `counter` child of F with `type` `LINE`. A duplicate key is FAIL.
  5. Cross-check: the sum of per-file `covered` equals `LINE_COVERED` and the sum of per-file `missed` equals `LINE_MISSED`, else FAIL. `SOURCEFILE_COUNT` = number of keys.
  6. Line lookup `L(key, nr)`: the `line` children of the sourcefile with that key whose `[int]nr` equals `nr`; report `ci` and `mi`, or `ABSENT` when none exists.
  7. Threshold: PASS if and only if `LINE_TOTAL -gt 0` and `100 * LINE_COVERED -ge 85 * LINE_TOTAL` (integer arithmetic). The 85% line default governs because the root `CLAUDE.md` states no coverage threshold (`.claude/rules/general-unit-test.md`, Coverage Requirements).

        $records = Install-PoshQCTool -SetTls { } -GetRepository $untrustedGallery -RegisterRepository { } -SetRepository $failingSetRepository -FindModule $script:PresentModule -InstallModule $script:NoOpInstall 3>&1 6>&1

        $verbose = @($records | Where-Object { $_ -is [System.Management.Automation.VerboseRecord] -and $_.Message -like 'Unable to enforce TLS 1.2*tls unavailable' })
