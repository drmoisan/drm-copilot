## Scope and recorded design decisions

- D1 — Comparator contract and algorithm (operator decision and orchestrator assumption, not reopened). `compareCodePoint(left: string, right: string): number` in `extensions/drm-copilot/src/lib/string-ordering.ts` is a strict total order over every JavaScript string, returns exactly -1, 0, or 1, returns 0 only for identical strings, sorts a proper prefix first, and equals Unicode code-point order for well-formed strings. The plan fixes the algorithm the spec names as one satisfying approach, so the executor has no algorithm choice: at the first differing UTF-16 code unit, each unit is ranked by a module-private `rankCodeUnit(unit: number): number` that returns `unit + 0x2000` for 0xD800..0xDFFF, `unit - 0x800` for 0xE000..0xFFFF, and `unit` otherwise; the lower rank sorts first. The mapping is injective, so lexicographic comparison over ranked units is a strict total order. On well-formed input it equals code-point order: a surrogate (start of a supplementary character) ranks above every non-surrogate BMP unit, two differing high surrogates and two differing low surrogates keep their numeric order, and units below 0xD800 and within 0xE000..0xFFFF keep their relative order.
- D2 — Module placement and imports. The new module has no import statement and no `require(`. Consumers import it directly with IMPORT-LINE; `pr-context/models.ts` neither defines nor re-exports it; no `index.ts` re-exports it. IMPORT-LINE is placed immediately before the first existing import whose specifier starts with `./`, or after the last import when no such import exists, or directly after the module header comment when the file has no import (`claude-blast-radius-derive-manifests.ts` and `quick-pick-labels.ts`).
- D3 — Coverage thresholds. `jest.config.cjs` gains exactly one entry, for `./src/lib/string-ordering.ts` (spec AC-7). The file is 470 lines at planning time; per-file entries for the 12 changed files that lack one (research section 4) would add at least 48 lines and take it past the 500-line limit. Those 12 files are instead held to 85/75 by the numeric per-file check in P4-T6 (AC-9), which applies to all 27 production files together with the zero-uncovered-changed-lines condition of the coordinator standing decision of 2026-10-09; a file that fails is brought into compliance by the add-tests branch (P4-T18 to P4-T34), not by a threshold entry. This is the plan decision the spec delegates (spec "Required configuration keys and defaults").
- D4 — Regression-test placement (500-line limit).
