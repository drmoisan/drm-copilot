```text
/**
 * Validate and normalize a safe repository-relative POSIX path. Empty and `.`
 * segments are dropped and an empty result becomes `.`, as Python
 * `PurePosixPath(value).as_posix()` does, so the readiness gate and plan
 * pairing derive the same path in both runtimes.
 */
export function repositoryRelativePath(
  value: unknown,
  field: string,
): { readonly path?: string; readonly errors: string[] } {
  if (typeof value !== "string" || value.trim().length === 0) {
    return {
      errors: [`${field} must be a non-empty repository-relative path.`],
    };
  }
  if (value.includes("\\")) {
    return { errors: [`${field} must use forward slashes.`] };
  }
  const parts = value
    .split("/")
    .filter((part) => part.length > 0 && part !== ".");
  if (
    value.startsWith("/") ||
    /^[A-Za-z]:/.test(value) ||
    parts.includes("..")
  ) {
    return { errors: [`${field} must stay within the workspace root.`] };
  }
  return { path: parts.length === 0 ? "." : parts.join("/"), errors: [] };
}

/** Return the `plan_path` the readiness gate derives, if any. */
function derivedPlanPath(
  feature: Readonly<Record<string, unknown>>,
): string | undefined {
  return repositoryRelativePath(feature["plan_path"], "plan_path").path;
}
```

## Inline awk programs

The worktree isolation guard refuses `awk -f <file>` (cycle-1 deviation 2), so every awk command passes one of these programs inline as a single-quoted argument. Commands below write the program name in capitals (for example `awk -v target=epic_planner_readiness.py 'AWK_FILE' artifacts/python/lcov.info`); the executor substitutes the exact one-line text and records the substituted command in `Command:`. These are the cycle-1 helper programs joined onto one line.

- `AWK_TOTALS`: `{ sub(/\r$/, "") } /^SF:/ { files += 1 } /^LF:/ { lf += substr($0, 4) } /^LH:/ { lh += substr($0, 4) } /^BRF:/ { brf += substr($0, 5) } /^BRH:/ { brh += substr($0, 5) } END { printf "FILES=%d LH=%d LF=%d LINE_PCT=%.2f BRH=%d BRF=%d BRANCH_PCT=%.2f\n", files, lh, lf, (lf > 0 ? 100 * lh / lf : 0), brh, brf, (brf > 0 ? 100 * brh / brf : 0) }`
- `AWK_FILE` (with `-v target=<file name>`): `{ sub(/\r$/, "") } /^SF:/ { inside = (index($0, target) > 0); if (inside) { matched += 1; sf = $0 } } /^end_of_record/ { inside = 0 } inside && /^LF:/ { lf = substr($0, 4) + 0 } inside && /^LH:/ { lh = substr($0, 4) + 0 } inside && /^BRF:/ { brf = substr($0, 5) + 0 } inside && /^BRH:/ { brh = substr($0, 5) + 0 } END { printf "MATCHED=%d %s LH=%d LF=%d LINE_PCT=%.2f BRH=%d BRF=%d BRANCH_PCT=%.2f\n", matched, sf, lh, lf, (lf > 0 ? 100 * lh / lf : 0), brh, brf, (brf > 0 ? 100 * brh / brf : 0) }`
- `AWK_ZERO` (with `-v target=<file name>`; prints one uncovered line number per line): `{ sub(/\r$/, "") } /^SF:/ { inside = (index($0, target) > 0) } /^end_of_record/ { inside = 0 } inside && /^DA:/ { split(substr($0, 4), parts, ","); if (parts[2] + 0 == 0) print parts[1] }`
- `AWK_ADDED` (reads a `git diff -U0` capture of one file; prints one added post-change line number per line): `{ sub(/\r$/, "") } /^@@ / { split($3, plus, ","); start = substr(plus[1], 2) + 0; count = (plus[2] == "" ? 1 : plus[2] + 0); for (i = 0; i < count; i++) print start + i }`

**Uncovered-added-line count.** `grep -c -x -F -f` with an empty pattern file prints nothing on this host (cycle-1 deviation 6), so the count is computed without a pattern file: `sort -u <zero list> > <zero sorted>`, `sort -u <added list> > <added sorted>`, `comm -12 <zero sorted> <added sorted> > <intersection>`, then `grep -c -e '.' <intersection>`, which prints `0` (exit 1 by design) for an empty intersection file.

**Stems and targets** used by the per-file coverage tasks: `py-validator` = `validate_epic_planner_state.py`, `py-lb` = `_epic_orchestrator_state_launch_binding.py`, `py-git` = `epic_planner_git_integrity.py`, `py-ready` = `epic_planner_readiness.py`, `ts-core` = `epic-planner-state-core.ts`, `ts-lb` = `epic-orchestrator-state-launch-binding.ts`, `ts-git` = `epic-planner-git-integrity.ts`, `ts-ready` = `epic-planner-readiness-integrity.ts`. Each target name matches exactly one `SF:` record (`MATCHED=1`).
