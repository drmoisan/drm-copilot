## Standing Notes

- **Child PRs receive no CI.** `.github/workflows/ci.yml` and `npm-audit-gate.yml` declare
  `pull_request: branches: [main, development]`, so a PR whose base is
  `epic/parallel-orchestration-integration` schedules no run. Each child's merge-on-green gate is
  therefore satisfied by the genuine absence of required checks, not by waiving an expected one,
  and each child runs the repository quality gates locally instead. The consequence is that the
  final integration-to-`main` PR is the first time CI evaluates any of this epic's code, and it
  evaluates all eight features at once. Budget for remediation on that PR.
- **Agent worktrees are based on `origin/main`.** `Agent(isolation: "worktree")` does not branch
  from the invoking worktree's HEAD. Child prompts must re-base onto the integration branch
  explicitly.
- **Agent memory does not survive a worktree.** `.claude/agent-memory/` is gitignored, so a child's
  memory files must be copied out before its worktree is removed.
