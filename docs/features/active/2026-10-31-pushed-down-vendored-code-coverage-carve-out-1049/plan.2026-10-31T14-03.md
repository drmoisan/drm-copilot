- [ ] [P2-T1] Create `PQ/PoshQC.VendoredCoverage.psm1` (Windows PowerShell 5.1 compatible, comment-based help on each function, at most 450 logical lines):
  - `Get-PoshQCCanonicalContentHash -Bytes` normalizes at byte level (each `0D 0A` to `0A`, then each remaining `0D` to `0A`; nothing else) and returns lowercase hex from `[System.Security.Cryptography.SHA256]::Create().ComputeHash([byte[]])`.

  - `Get-PoshQCVendoredCoverageStatus -Root -CandidatePaths [-ReadBytes] [-TestPathExists] [-TestReparsePoint] [-WarningLogger]` returns one record per manifest entry and per candidate not in the manifest, each with `path`, `status` (`exempt`, `modified`, `missing`, `unlisted`), `manifest_sha256` and `actual_sha256`, sorted ordinally by `path`; matching is ordinal and case-sensitive; a reparse point is `modified` with `actual_sha256` null; an absent manifest logs exactly one warning naming `.push-down-manifest.json` and reports every candidate `unlisted`.
