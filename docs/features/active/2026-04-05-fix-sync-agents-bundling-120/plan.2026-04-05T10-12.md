## Overview

Fix the preamble crash bug in `sync-agents-from-instructions.ps1` (Issue #120) and add compaction logic to reduce redundant content in generated `AGENTS.md` output. The fix makes `.github/copilot-instructions.md` optional so the script succeeds in workspaces that lack the preamble file. Compaction strips known redundant patterns (cross-reference boilerplate, repeated reading-order statements, verbose suppression examples, duplicate toolchain commands) from instruction bodies before embedding.
