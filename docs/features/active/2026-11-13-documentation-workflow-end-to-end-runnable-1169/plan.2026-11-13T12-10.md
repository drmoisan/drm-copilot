- No new Python. New code and tests are PowerShell; enforcement hooks invoke no Python.
- Evidence is append-only; every timestamp is read from the clock; no artifact records an absolute path. SCRATCH resolves to `<session scratchpad>/issue-1169/`, recorded as the token `SCRATCH`.
- Cadence follows `## Test Cadence (Mandatory)` of `atomic-plan-contract`: a task check after every task (`<FEATURE>/evidence/other/task-check.P<N>-T<M>.<timestamp>.md`), the full loop at each `[phase-gate]` task (`<FEATURE>/evidence/qa-gates/phase-gate.P<N>.<timestamp>.md`) and in Phase 6.

- Pre-mortem and self-review precede every push.
- Edits to the execution-environment brief and to both `pack-manifests/core.json` files land outside every region recorded under `docs/engineering/process-reductions/` (revert-block `Current` text, and stored-patch hunks with their context lines, such as the 0010 hunks around the `epic-wave-barrier-early-start.ps1` entries); `tests/scripts/dev-tools/ProcessReductionChain.Ledger.Tests.ps1` stays passing.
