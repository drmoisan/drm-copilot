## Conventions for This Plan

- Evidence file names are `<name>.<timestamp>.md`. `<timestamp>` is the UTC time read from the host clock immediately before the file is written, in the shape `yyyy-MM-ddTHH-mm` with no zone suffix (for example from `date -u +%Y-%m-%dT%H-%M`); it is never composed in advance.
