## Rewrite Rule (Single Source of Truth)

The bundle import-path rewrite is a uniform, statement-anchored prefix substitution applied ONLY to import statements:

- `from scripts.dev_tools.` -> `from dev_tools.`
- `import scripts.dev_tools.` -> `import dev_tools.`

The rule is anchored to the leading `from ` / `import ` keyword tokens. Docstring prose and comments that contain the substring `scripts.dev_tools.` (for example `` ``scripts.dev_tools.validate_orchestration_artifacts`` `` inside a module docstring) are NOT import statements and MUST remain unchanged in the bundle. This anchoring is mandatory: the parity guard test (Phase 2) applies the identical anchored rule, so any deviation (rewriting docstring prose, or failing to rewrite an import) will fail the parity test deterministically.

Per research, `_orchestrator_state_human_interaction.py` (imports only stdlib `typing`) and `validate_policy_audit_artifact.py` (imports only stdlib `re`) require zero import rewrites; their bundled copies are byte-identical to source.
