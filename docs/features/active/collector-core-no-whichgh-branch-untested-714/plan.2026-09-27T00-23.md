## Plan Conventions

- **Executor environment:** the executor's shell allowlist is `npx prettier *`, `npx eslint *`, `npx tsc *`, `npx jest *`, `git *`, and `cd extensions/drm-copilot && npx <tool> *` command chains built from those same allowed tools. It cannot run `npm run ...`, `node ...`, `pwsh`, `bash`, or `wsl`. Toolchain commands (prettier, eslint, tsc, jest) run as `cd extensions/drm-copilot && npx <tool> ...`, with all arguments given relative to `extensions/drm-copilot`. The repository root has no `node_modules` and is not an npm workspace of `extensions/drm-copilot`, and `npx` searches only its own cwd and that cwd's ancestors; a toolchain command invoked from the worktree root therefore fails, confirmed by direct execution: from the worktree root, `npx tsc -p extensions/drm-copilot/tsconfig.json --noEmit` exits 1 with `This is not the tsc command you are looking for`, and the equivalent `npx jest --config extensions/drm-copilot/jest.config.cjs --coverage ...` form reports "Coverage data ... was not found" for roughly 50 files and exits 1. Git commands still run from the worktree root, unchanged. Non-shell tools (Read/Grep/Glob/Edit/Write) remain available for file inspection and evidence authoring and are not subject to the shell allowlist.
- **Dependency precondition:** every `npx eslint`/`npx tsc`/`npx jest` command requires `extensions/drm-copilot/node_modules` to contain the installed devDependencies. Installing them (`npm ci` run in `extensions/drm-copilot`) is an orchestrator responsibility performed before execution is delegated; the executor does not install dependencies. Node-modules presence is necessary but not sufficient: the command must also be invoked with `extensions/drm-copilot` as its cwd (the `cd extensions/drm-copilot && npx ...` form below), because `npx` resolves packages from its own cwd and ancestors only, and the worktree root is not an ancestor-relative workspace of `extensions/drm-copilot`. `npx prettier` is exempt from the node_modules requirement but not from the cwd requirement.
- **No production file is written by this plan.** The only non-evidence file this plan creates is `extensions/drm-copilot/test/lib/pr-context/collector-core-default-resolver.test.ts` (Phase 1).
- **Command forms (verified directly against the current tree by command execution in this planning round; see the Planner Internal Review Record for citations):**
  - Format (read-only check): `cd extensions/drm-copilot && npx prettier --check "src/**/*.ts" "test/**/*.ts" "*.json" "*.cjs"`
  - Lint: `cd extensions/drm-copilot && npx eslint --no-error-on-unmatched-pattern --config eslint.config.mjs src test`
  - Type-check: `cd extensions/drm-copilot && npx tsc -p tsconfig.json --noEmit` (this tsconfig's `include` is `src/**/*.ts` only — pre-existing project scope, unchanged by this plan; `test/**/*.ts` is type-checked separately by `ts-jest` during the Jest run)
  - Test with coverage: `cd extensions/drm-copilot && npx jest --config jest.config.cjs --coverage --coverageReporters=lcov --coverageReporters=text-summary` (equivalent to the extension's own `test:coverage` script)
  - Coverage artifact: `extensions/drm-copilot/coverage/lcov.info` (per `jest.config.cjs`'s `coverageDirectory: "<rootDir>/coverage"`, where `<rootDir>` resolves to the directory of the `--config` file, i.e. `extensions/drm-copilot` when the command is run with that cwd)
- **Anchor discipline:** every reference to the `whichGh === undefined` conditional locates it by that literal text at execution time (Phase 0, [P0-T8]), never by a fixed line number, per spec.md D5/Risk.
- **Evidence paths:** all evidence this plan produces is written under `docs/features/active/collector-core-no-whichgh-branch-untested-714/evidence/<kind>/`, per the canonical scheme. No `artifacts/baselines/`, `artifacts/qa/`, or similar non-canonical path is used anywhere in this plan.
- **Restart rule:** if any Phase 3 step fails, or a step that runs in write mode changes a tracked file, restart the Final QC Loop at [P3-T1].
