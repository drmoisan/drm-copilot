## Design Decisions

- Helper `scripts/ci/Select-PythonTestShard.ps1` (new, PowerShell) imports `scripts/powershell/PoshQC/PoshQC.Shard.psm1` and reuses `Select-PoshQCShardTestFile`, `Test-PoshQCShardCompleteness`, and `Test-PoshQCShardTestCount`; the module and its mirror copies stay unchanged. It follows the entry-function pattern of `scripts/ci/Invoke-CiRequiredGate.ps1` (`Invoke-CiRequiredGateEntry`): logic in functions with injected seams, a thin guarded entry call.
- Weights are LF-normalized byte size. `Select-PoshQCShardTestFile` has no `ReadTestFileText` seam, and `Get-PoshQCShardTestFileWeight` weighs a `FileInfo` by reading the real file, an object by its unnormalized `Length`, and a bare string as 1. The helper therefore reads each file's text through its own injected `ReadTestFileText` reader and passes `[pscustomobject]` items with `FullName` and `Length` equal to the UTF-8 byte count of the text after CRLF is replaced by LF. It also passes a `ReadWeightsText` seam that returns `$null`, because the default reader would load `config/poshqc-shard-weights.json` (PowerShell milliseconds) and weigh every `.py` file at the median. No Python weights file is created; a third shard is the rollout fallback.
- `_quality-checks.yml`: job `quality-checks7` keeps its id with matrix `["3.11", "3.12"]`. New jobs: `python-static-313` (name `Python 3.13 static`), `python-coverage-shard` (name `Python 3.13 coverage shard ${{ matrix.shard }}`, matrix `[1, 2]`, `-ShardCount ${{ strategy.job-total }}`), and `python-coverage-combine` (name `Code Quality & Tests (3.13)`, `needs` both, job `if: always()`, first step requires both to succeed, every step gated on `inputs.run-heavy`). Shard and static jobs carry job-level `if: ${{ inputs.run-heavy }}`. The step name `Run tests with Pytest and coverage` stays unique, in the shard job.
- Per-shard data: `COVERAGE_FILE` set to a non-dot name under `artifacts/python/`, JUnit `artifacts/python/junit-shard-<n>.xml`, manifest `artifacts/python/shard-files.json`, artifact `python-coverage-shard-<n>`. The combine job runs `coverage combine`, `coverage xml -o coverage.xml`, `coverage json -o artifacts/python/coverage.json`, then the unchanged threshold step (85 line, 75 branch) and unchanged Codecov step; completeness uses the helper's verify mode (manifest completeness plus JUnit sum against `pytest --collect-only -q` count).
