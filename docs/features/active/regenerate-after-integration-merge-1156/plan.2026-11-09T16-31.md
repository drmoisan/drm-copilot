## Execution Rules

- Test gates are parallel only: one `Invoke-PoshQCParallelTest` run, one `pytest -n auto` run, Jest through its normal parallel workers; each is re-run only after a fix. A focused single-file run is debugging only and is never evidence. Order dependence found by a gate is fixed on both the leaking and the affected suite.

At the start of every task that edits a shared file (both epic-scope gate files, both merge-gate entry files, the orchestrate, epic-orchestrate, parallel-orchestrate, and execution-environment skills, both agents, `.claude/rules/orchestrator-state.md`, `tests/scripts/dev_tools/parallel_orchestrator_surface_expectations.py`, both `pack-manifests/core.json`), the executor re-reads the file as it stands and edits by heading or symbol anchor.
