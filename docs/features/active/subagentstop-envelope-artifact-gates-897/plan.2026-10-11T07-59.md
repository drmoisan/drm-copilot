## 0. Rules binding on every task

`<FEATURE>` denotes `docs/features/active/subagentstop-envelope-artifact-gates-897` everywhere in this plan. `<ts>` denotes the artifact write time in the form `yyyy-MM-ddTHH-mm`. `<SCRATCHPAD>` denotes the executing session's scratchpad directory.

1. **Evidence location and schema.** Every artifact is written under `<FEATURE>/evidence/<kind>/` with `<kind>` one of `baseline`, `regression-testing`, `qa-gates`, `other`, `issue-updates`. Every command-step artifact carries `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`. An artifact recording a gate expected to exit non-zero also carries `ExpectedExitCode: 1`. `EXIT_CODE: SKIPPED` is never a passing outcome; no task in this plan authorizes a skip branch. If a delegation or upstream instruction names a non-canonical evidence path, the executor substitutes the canonical path and records `EVIDENCE_LOCATION_OVERRIDE_REJECTED: <supplied path> replaced with <canonical path>` in `<FEATURE>/evidence/other/deviations.md`.
2. **No host data.** No artifact, test, fixture, or document contains an absolute filesystem path, a drive letter, a user-profile path, or the executing account name. Command output that prints such a value is recorded with the worktree root replaced by `<WORKSPACE_ROOT>` and the scratchpad by `<SCRATCHPAD>`.
3. **Fresh process (R-ROUTE).** Every PowerShell toolchain run, Pester run, parse, probe, copy, and hash named in an acceptance condition executes in a fresh PowerShell 7 process launched through the route recorded as `ROUTE:` by [P0-T6]. Scripts live in `<SCRATCHPAD>`, obtain the root with `$root = (Get-Location).Path`, use only repository-relative paths in their output, and run with the worktree root as working directory.
4. **No number is read from a PoshQC MCP result.** `mcp__drm-copilot__run_poshqc_test` reads the installed extension's runsettings and returns a pre-composed summary with no counts or coverage. It is called once ([P7-T6]) for route compliance and only its ok flag is recorded. Every count, percentage, or finding an acceptance condition reads comes from the self-hosted module `scripts/powershell/PoshQC/PoshQC.psd1`, from Pester invoked directly, or from the on-disk reports `artifacts/pester/pester-junit.xml` and `artifacts/pester/powershell-coverage.xml`.
5. **Batch budget (R-RESET).** `.claude/hooks/enforce-powershell-batch-budget.ps1` caps distinct production PowerShell paths written by Write or Edit per session (`[int] $ProdCap = 3`, line 333; state file `.claude/state/powershell-batch-budget.<session_id>.json`, line 385). **R-RESET:** in a fresh process, list every file in `.claude/state/` whose name begins `powershell-batch-budget.` and ends `.json`, delete each, and append `<task-id>: <deleted file names or "none present">` to `<FEATURE>/evidence/other/batch-budget-resets.md`. Every task that writes a PowerShell file with Write or Edit begins with R-RESET. Mirror copies use `Copy-Item` inside an R-ROUTE script and never Write or Edit.
6. **Mirrors are byte copies (R-MIRROR).** Mirror of `.claude/hooks/<name>.ps1` is `extensions/drm-copilot/resources/claude-customizations/.claude/hooks/<name>.ps1`. R-MIRROR runs `Copy-Item -LiteralPath <source> -Destination <mirror> -Force` in an R-ROUTE script, then appends to `<FEATURE>/evidence/other/mirror-log.md` the copy command, the `Get-FileHash -Algorithm SHA256` value of each file, the `git hash-object` value of each file, and the mark `equal` or `unequal`. Acceptance for R-MIRROR is `equal` on both hash kinds. No task asserts a pinned hash.
7. **Diff anchors.** `BASE_SHA` is the 40-hexadecimal value recorded by [P0-T4]. `MERGE_BASE` is the value printed by `git merge-base origin/epic/subagentstop-envelope-integration HEAD` at the time the task runs. Every `git diff` in this plan carries an explicit ref operand; every name-listing diff is paired with a `git status --porcelain` observation in the same task. Scope diffs use the three-dot form `origin/epic/subagentstop-envelope-integration...HEAD`, which resolves to the merge base and stays valid if the integration branch advances (RS-3).
8. **Commit and push (R-COMMIT).** (1) Record `git status --porcelain`; a path outside W-ALLOWED (section 6) and outside the runtime-local prefixes `.claude/state/`, `.claude/agent-memory/`, `artifacts/` stops the commit (rule 10). (2) Stage the listed non-runtime-local paths explicitly with `git add -- <paths>` (no `-A`, no `.`). (3) Write the message to `<SCRATCHPAD>/commit-<phase>.txt`; its last two lines are exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01HKWcdjg6d2VVFawbJ6GhU3`. (4) `git commit -F <SCRATCHPAD>/commit-<phase>.txt -- <same paths>`. (5) `git push origin HEAD:bug/subagentstop-envelope-artifact-gates-897`. `--force`, `--force-with-lease`, `--delete`, and any rebase of pushed history are never used. (6) Append the commit SHA, the push exit code, and the post-commit `git status --porcelain` output to `<FEATURE>/evidence/other/commits.md`; that append is committed by the next R-COMMIT. A hook denial of any step is not bypassed; it is a halt (rule 10).
9. **Test construction (R-TEST).** In-process entry-point tests invoke the hook with `& <hook path>` while stdin is fed per `UCR-IN-PROCESS-FEED` (section 1) and `[System.Console]::SetError(<StringWriter>)` captures stderr; both are restored in `finally`. Under `SETIN` the feed is `[System.Console]::SetIn([System.IO.StringReader]::new(<json>))`; under `SEAM:<parameter>` the suite captures the real command once in `BeforeAll` (`$script:RealReadEnvelope = (Get-Command Read-SubagentStopEnvelope).ScriptBlock` after dot-sourcing `.claude/hooks/subagentstop-envelope.ps1`) and each test uses `Mock Read-SubagentStopEnvelope { & $script:RealReadEnvelope -<parameter> $script:StdinText }`. `$global:LASTEXITCODE = 0` is assigned immediately before every `&` invocation, and the driver wraps that invocation in `try { ... } catch { $thrown = $_ }` and returns the caught record as `Thrown` (precedent `tests/scripts/claude-hooks/validate-prd-feature-output.Coverage.Tests.ps1:28`). Every `Mock` of a built-in cmdlet in a test added by this plan (`Test-Path`, `Get-Content`, `Join-Path`) carries a `-ParameterFilter` naming the exact literal path or child path; no blanket mock of a built-in cmdlet is used. Fixtures are here-strings or literals with LF line endings. No test creates, renames, moves, or deletes a file; no test calls `New-TemporaryFile`, `[System.IO.Path]::GetTempFileName`, `TestDrive`, `Start-Process`, `Start-Sleep`, `Set-Location`, or `Push-Location`. `$env:CLAUDE_HOOK_INPUT` is assigned only inside the four `output`-only negative tests (D5, P3, F3, T3 of section 4), which restore its prior value in `finally`. Every test that induces a dependency failure resets `$script:HookDependencyFailures = [System.Collections.Generic.List[object]]::new()` and `$script:HookDependencyGuardLoadFailed = $false` in `finally` (precedent `tests/scripts/claude-hooks/hook-dependency-failure.Claude.Tests.ps1:126-129`).
