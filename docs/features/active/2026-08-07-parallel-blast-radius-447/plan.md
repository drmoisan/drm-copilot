1. Do NOT modify `.claude/skills/atomic-plan-contract/SKILL.md`, any file under `.claude/rules/`, or any file under `.github/instructions/`.
2. Additive only. Do NOT modify or refactor existing epic implementations (`scripts/dev_tools/epic_wave_computation.py`, epic hooks, epic validators). Exactly three existing files may be edited, and every such edit is append-only: (a) `scripts/powershell/PoshQC/settings/pester.runsettings.psd1` and (b) its byte-parity bundled mirror `extensions/drm-copilot/resources/powershell/PoshQC/settings/pester.runsettings.psd1`, which receive the identical `CodeCoverage.Path` entry (P4-T4), because `tests/scripts/dev_tools/test_poshqc_bundled_parity.py` locks those two files to exact text parity; and (c) `extensions/drm-copilot/resources/claude-customizations/pack-manifests/core.json`, which receives the pack-manifest entry (P4-T7). No other existing file may be edited. Separately, every new `.claude/**` file must be created with a byte-identical counterpart under `extensions/drm-copilot/resources/claude-customizations/.claude/` (P4-T7), because `tests/scripts/dev_tools/test_push_down_claude_resource_contracts.py::test_bundled_claude_payload_contains_all_repo_runtime_contracts` asserts root-to-bundle byte parity for the whole `.claude/**` tree; these are file creations, not edits.
3. The surface is named `parallel` throughout; the contention relation fails closed; key-level partitioning of shared surfaces is out of scope.
4. No production, test, or reusable script file may exceed 500 lines. Use the facade + `_blast_radius_extraction.py` split; add `_blast_radius_validation.py` (Python) or `BlastRadiusExtraction.psm1` (PowerShell) only if a file approaches the limit. Any additional PowerShell production module must also be appended to `CodeCoverage.Path`.
5. No new dependencies: no `hypothesis`, no YAML parser. Python stdlib and existing dev dependencies only; PowerShell built-ins only.
6. Determinism and purity: `computed_at` is caller-supplied; the library performs no filesystem reads/writes, no subprocess, no network, and no wall-clock reads at runtime. Tests use no temp files, no sleeps, no network. Fixture corpus files are committed and read-only.
7. Evidence artifacts are written only under `docs/features/active/2026-08-07-parallel-blast-radius-447/evidence/<kind>/` (canonical scheme). `artifacts/` evidence sub-paths are forbidden. Every command-step evidence artifact records `Timestamp:` (ISO-8601 `yyyy-MM-ddTHH-mm`), `Command:`, `EXIT_CODE:`, and `Output Summary:`; test-step artifacts include numeric coverage headline values.
8. Both languages sort and deduplicate all collections at construction using ordinal string comparison (PowerShell: `[StringComparer]::Ordinal`).
