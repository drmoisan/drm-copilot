## Execution Rules

1. **Evidence location.** Every artifact is written under `docs/features/active/subagentstop-envelope-orchestrator-family-903/evidence/<kind>/` with kind `baseline`, `regression-testing`, `qa-gates`, or `other`. Paths under `artifacts/` are never used for evidence.
2. **Timestamps.** `<ts>` in an artifact name is the execution time of that task in `yyyy-MM-ddTHH-mm` form. Each command-step artifact carries `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`; an artifact whose expected exit code is non-zero also carries `ExpectedExitCode: <int>`.
3. **Scratch scripts.** `<SCRATCHPAD>` is the executing session's scratchpad directory. Appendix A scripts are saved there verbatim with the Write tool (UTF-8 without BOM, LF line endings) and are never committed. No artifact records an absolute host path; host-specific prefixes are replaced with `<SCRATCHPAD>` or `<REPO>`.
4. **PowerShell route and argument form.** PowerShell scripts are launched as `sh <SCRATCHPAD>/run-ps.sh <SCRATCHPAD>/<script>.ps1 <arguments>` (route `sh`). If that route is refused, the PowerShell tool runs `& <SCRATCHPAD>/<script>.ps1 <arguments>` from the repository root (route `powershell-tool`). [P0-T7] records the selected route; every later PowerShell command uses it. Set-valued arguments to A1 (`-TestPath`, `-CoveragePath`), A7 (`-Name`), and A9 (`-Path`) are passed as one comma-joined token with no spaces (for example `-TestPath a.Tests.ps1,b.Tests.ps1`), because `pwsh -File` binds a space-separated list as separate positional arguments. A2, A3, A4, A5, A6, and A10 take space-separated paths (they declare `ValueFromRemainingArguments`).
5. **No MCP PoshQC numbers.** The MCP PoshQC runners are not used for any acceptance value. Format, analyzer, and Pester results come only from the Appendix A scripts, which print their result lines unconditionally on every run.
6. **Observe before asserting.** Before checking off any task whose acceptance reads a printed value, confirm the value appears in that run's output. The first run of each Appendix A script is in Phase 0; if a required line is absent there, halt and report.
7. **Search tool.** Shell commands are POSIX-shell syntax for the Bash tool: a pattern containing `$` is single-quoted, and a pattern that begins with `-` is passed with `-e`. If `rg` is not on PATH (exit 127), use the Grep tool with the identical pattern and file list and record `TOOL: Grep`. `rg` exits 1 when nothing matches; a "no match" acceptance records `EXIT_CODE: 1`, `ExpectedExitCode: 1`, and empty match output. Exit code 2 is a failure. A "match count" is the number of output lines of the stated `rg -n` command. Any git argument of the form `<ref containing />:<path>` is run with the `MSYS_NO_PATHCONV=1` prefix.
8. **Halt rule.** A task that reaches a stated halt condition stops execution, records `BLOCKED: <reason>` in its artifact, and returns to the caller. The executor does not improvise around a halt, and never creates, copies, or stubs the E1 helper.

A1 `pester-run.ps1`:

```powershell
param(
    [Parameter(Mandatory)][string[]] $TestPath,
    [string[]] $CoveragePath = @(),
    [string] $CoverageOutputPath = '',
    [string] $ReportPath = ''
)
$TestPath = @($TestPath | ForEach-Object { $_ -split ',' } | Where-Object { $_ })
$CoveragePath = @($CoveragePath | ForEach-Object { $_ -split ',' } | Where-Object { $_ })
if ($CoveragePath.Count -gt 0 -and -not $CoverageOutputPath) { throw 'CoverageOutputPath is required when CoveragePath is supplied.' }
$configuration = New-PesterConfiguration
$configuration.Run.Path = $TestPath
$configuration.Run.PassThru = $true
$configuration.Output.Verbosity = 'Detailed'
if ($CoveragePath.Count -gt 0) {
    $configuration.CodeCoverage.Enabled = $true
    $configuration.CodeCoverage.Path = $CoveragePath
    $configuration.CodeCoverage.OutputPath = $CoverageOutputPath
}
$result = Invoke-Pester -Configuration $configuration
$report = [System.Collections.Generic.List[string]]::new()
$report.Add("TotalCount=$($result.TotalCount)")
$report.Add("PassedCount=$($result.PassedCount)")
$report.Add("FailedCount=$($result.FailedCount)")
$report.Add("FailedContainersCount=$($result.FailedContainersCount)")
foreach ($failedTest in $result.Failed) { $report.Add("FAILED: $($failedTest.ExpandedPath)") }
foreach ($failedContainer in $result.FailedContainers) { $report.Add("FAILED-CONTAINER: $($failedContainer.Item)") }
if ($CoveragePath.Count -gt 0) {
    $executed = @($result.CodeCoverage.CommandsExecuted)
    $missed = @($result.CodeCoverage.CommandsMissed)
    foreach ($file in $CoveragePath) {
        $fullPath = (Resolve-Path -LiteralPath $file).Path
        $hitLines = @($executed | Where-Object { $_.File -eq $fullPath } | ForEach-Object { $_.Line } | Sort-Object -Unique)
        $missLines = @($missed | Where-Object { $_.File -eq $fullPath } | ForEach-Object { $_.Line } | Sort-Object -Unique | Where-Object { $hitLines -notcontains $_ })
        $analyzed = @(@($hitLines) + @($missLines) | Sort-Object -Unique)
        $percent = if ($analyzed.Count -eq 0) { 'NA' } else { [math]::Round(100 * $hitLines.Count / $analyzed.Count, 2) }
        $report.Add("COVERAGE file=$file AnalyzedLines=$($analyzed.Count) CoveredLines=$($hitLines.Count) LinePercent=$percent")
        $report.Add("HIT file=$file Lines=$($hitLines -join ',')")
        $report.Add("MISSED file=$file Lines=$($missLines -join ',')")
    }
}
$report | Write-Output
if ($ReportPath) { $report | Set-Content -LiteralPath $ReportPath -Encoding UTF8 }
if ($result.FailedCount -gt 0 -or $result.FailedContainersCount -gt 0) { exit 1 }
exit 0
```

```powershell
# Restates the three atomic-plan-contract requirements that the Python oracle does not check:
# Phase 0 policy-read and baseline wording, an explicit path in every task, QA wording in the final phase.
function Test-PlanContractPredicate([string[]] $Lines) {
    $phasePattern = '^### Phase (\d+) ' + [string][char]0x2014 + ' (.+)$'
    $titles = @{}
    $tasks = @{}
    $current = -1
    foreach ($line in $Lines) {
        $phase = [regex]::Match($line, $phasePattern)
        if ($phase.Success) {
            $current = [int]$phase.Groups[1].Value
            $titles[$current] = $phase.Groups[2].Value
            if (-not $tasks.ContainsKey($current)) { $tasks[$current] = [System.Collections.Generic.List[string]]::new() }
            continue
        }
        if ($line.StartsWith('### Phase ')) { $current = -1; continue }
        $task = [regex]::Match($line, '^- \[[ xX]\] \[P\d+-T\d+\] (.+)$')
        if ($task.Success -and $current -ge 0) { $tasks[$current].Add($task.Groups[1].Value.Trim()) }
    }
    if ($titles.Count -eq 0 -or -not $tasks.ContainsKey(0) -or $tasks[0].Count -eq 0) { return $false }
    $phaseZero = $tasks[0] -join "`n"
    if ($phaseZero -notmatch '(?i)\b(policy|instruction|read)\b' -or $phaseZero -notmatch '(?i)\bbaseline\b') { return $false }
    foreach ($key in @($tasks.Keys)) {
        foreach ($text in $tasks[$key]) { if (-not [regex]::IsMatch($text, '(?i)(?:[.\w*?-]+[\\/])+[.\w*?-]+')) { return $false } }
    }
    $maxPhase = [int](($titles.Keys | Measure-Object -Maximum).Maximum)
    $finalText = (@($titles[$maxPhase]) + @($tasks[$maxPhase])) -join "`n"
    return [regex]::IsMatch($finalText, '(?i)(qa|quality|toolchain|format|lint|type|test|coverage)')
}
```

`FALSE_NEGATIVES=` is informational. A hook that is a subset of its oracle passes some expected-block members, and no task asserts on this count. `CORPUS_VACUOUS=True` means no expected-pass member exists, so `FALSE_POSITIVES=0` holds without evidence; the corpus tasks report it rather than fail on it.

A14 `corpus-oracle.py` (Amendment B; saved by [P2-T11]; invoked by A13 through `poetry run python` from the repository root). It reads each requested blob with `git cat-file -p` at the pinned commit and applies the repository's context-free validators. The orchestrator types use completion flags. It prints one tab-separated `ORACLE` line per request.

```python
"""Scratch oracle for the corpus false-positive gate. Never committed."""

import subprocess
import sys
from pathlib import Path

sys.path.insert(0, str(Path.cwd()))

from scripts.dev_tools.validate_epic_orchestrator_state import (
    validate_epic_orchestrator_state_text,
)
from scripts.dev_tools.validate_orchestration_artifacts import validate_plan_text
from scripts.dev_tools.validate_orchestrator_state import (
    validate_orchestrator_state_text,
)
from scripts.dev_tools.validate_parallel_orchestrator_state import (
    validate_parallel_orchestrator_state_text,
)


def read_blob(sha: str, path: str) -> str:
    completed = subprocess.run(
        ["git", "cat-file", "-p", f"{sha}:{path}"], capture_output=True, check=True
    )
    return completed.stdout.decode("utf-8-sig")


def oracle_errors(kind: str, text: str) -> list[str]:
    if kind == "plan":
        return validate_plan_text(text)
    if kind == "orchestrator-state":
        return validate_orchestrator_state_text(
            text, require_complete=True, require_model_routing=True
        )
    if kind == "epic-orchestrator-state":
        return validate_epic_orchestrator_state_text(text, require_complete=True)
    if kind == "parallel-orchestrator-state":
        return validate_parallel_orchestrator_state_text(text, require_complete=True)
    return [f"unsupported kind {kind}"]


def main() -> int:
    sha, request_path = sys.argv[1], sys.argv[2]
    for raw in Path(request_path).read_text(encoding="utf-8-sig").splitlines():
        request = raw.strip()
        if not request:
            continue
        kind, path = request.split("\t", 1)
        try:
            count = len(oracle_errors(kind, read_blob(sha, path)))
        except Exception as error:
            count = 1
            print(f"ORACLE-EXCEPTION\t{path}\t{error}")
        print(f"ORACLE\t{kind}\t{path}\t{count}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
