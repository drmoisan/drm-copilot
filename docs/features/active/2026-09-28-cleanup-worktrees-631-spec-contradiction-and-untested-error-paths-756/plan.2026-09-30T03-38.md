**Evidence schema (ES):** every evidence file named in this plan contains the fields `Timestamp:`, `Command:`, `EXIT_CODE:`, and `Output Summary:`. Where a task states `ExpectedExitCode:` the artifact also carries that field, per `.claude/skills/evidence-and-timestamp-conventions/SKILL.md`. Artifact file names use the plan timestamp `2026-09-30T03-38`. On a Phase 2 loop restart the artifact of the same name is overwritten by the clean pass. Where a task records several commands, `EXIT_CODE:` is the exit code of the first command and every companion command's exit code is recorded in `Output Summary:`. An expected non-zero companion code (for example grep on a zero count) is stated there and never placed in `EXIT_CODE:`. All evidence lives under `docs/features/active/2026-09-28-cleanup-worktrees-631-spec-contradiction-and-untested-error-paths-756/evidence/<kind>/`.

**Environment-failure clause (EFC):** EFC applies to a local command task only when the command's combined output contains at least one of the literals `Missing required tool`, `syntax error`, `command not found`, `kcov not installed`, `bats not installed`, `npm error`, or `ENOENT`, and contains no line beginning `not ok`. The literal `bats not installed` is included because `run_test` in `scripts/bash/shell_qc_lib.sh` prints it and returns 0 without running any test. When EFC applies, the artifact records the observed EXIT_CODE and the line `EFC: TRIGGERED`, and the task is completed by the matching CI record tasks in Phase 2 (P2-T11 through P2-T15). EFC is the only skip branch authorized in this plan; it is not a SKIPPED outcome, because the CI record is mandatory in every case. When EFC does not apply, the command result itself decides the task.

**Sandbox routes:** the Bash tool in this worktree refuses command text containing the words bash, pwsh, or wsl, refuses heredocs, and refuses `cd ... &&` chains. Commands in this plan use `sh scripts/bash/shell-qc.sh <subcommand>` and `npx --yes bats --tap <file>`. Files are written with the Write and Edit tools, never with shell redirection.
