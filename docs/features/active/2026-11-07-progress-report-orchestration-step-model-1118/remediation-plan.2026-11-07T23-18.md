- `VERDICT(C)`: a step script ends with `exit ([int](-not (C)))`, so `EXIT_CODE:` is non-zero whenever condition C fails.
- Alias table (RF1), compared case-insensitively after trimming: `feature_review` and `S7_feature_review` to `review`; `atomic_execution` and `S5_atomic_execution` to `execution`; `S2_research` to `research`; `S3_spec` to `spec`; `S4_atomic_planning` to `plan`; `S4_preflight` to `preflight`; `S8_create_pr` to `pr`; `S9_ci_gate` and `S9_ci_green` to `ci`. `promotion` and every other unknown name stay `unmapped`. The `completed_steps` research fallback and the `next_step` research prefix accept `S2_research` or `S3b_research`.
- In-progress execution start (RF2): after the tick split of a plan file, an in-progress `execution` step of that plan file that carries a start takes the later of that start and the plan anchor's `LastTickUnixSeconds` (the anchor as updated by this run).
- Wording rules (RF3), asserted literals. Item mode is `Summary.Subject` equal to `Item`. Epic mode with one feature: `The only feature is not done yet.` or `The only feature is done.`; epic mode with more features keeps `None of the <N> features is done yet.` and `<K> of <N> features are done.` Item mode: `#<i> is not done yet.` or `#<i> is done.`, and the `No feature is running.` sentence is omitted. A blocked count of one prints `(1 blocked step excluded)` and `**Blocked:** 1 step excluded from the estimate`. Item-mode Full: State header `| State | Item |`, Running and Pending rows without a wave or band label (`| Running | #<i>: ...`, `| Pending | #<i> (<t>) |`), and the weekly line ends `points since the measurement started. This pool also covers the other runs in this session, so it is not this item's cost alone.` The `<k> of <n> types use defaults.` sentence, the Wave table, and every epic-mode multi-feature line are unchanged. TL;DR stays four lines.
