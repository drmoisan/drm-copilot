## Pre-Mortem

- Review checklists: a reviewer flags an `&` on a context member, a non-literal `$PSScriptRoot` use, a module missing the convention help token, a command module that prints or exits, an edit to a 1020 line outside a 1021 anchor, or a template naming the repository. Prevented by the context-call form fixed in [P0-T2], the scanning suites in [P5-T5], the closure tests in [P5-T4], the anchor-only diff in [P6-T9], `DocsPageTemplates.Tests.ps1` and `DocsNeutrality.Tests.ps1`, and the template walk in [P6-T13].
- Coverage: a module reached only through the command function could fall below 85%. Prevented by testing every pure function directly with in-memory inputs in Phases 2 to 4, reading per-file figures from `artifacts/pester/powershell-coverage.xml` in [P6-T3], and checking that the edited 1020 files do not lose coverage in [P6-T7]; no production file is excluded and no branch gate applies to Pester.
- Mirror parity: the bundle copy of an edited 1020 file goes stale when the source changes after the copy, and `CORE` can miss a template. Prevented by one copy step after the last source edit ([P5-T1]), a re-copy after any formatter or analyzer fix ([P6-T1], [P6-T2]), `Docs.Manifest.Tests.ps1` in [P5-T3], and the resource-contract and dependency-closure tests in [P5-T4] and [P6-T4]. The plan changes no fact stated in the execution-environment brief (no CI job, required context, tool route, or batch-budget rule), so no brief-update task is needed.
- File size: `DocsPageLinks.psm1` and `DocsPageFrontMatter.psm1` can pass 500 lines. Prevented by the spec refinement splits (`DocsPageAnchors.psm1`, `DocsPageMetadata.psm1`), each with its own suite, bundle copy, `CORE` entry, and classification row, and by the line counts in [P6-T10]. A test file nearing 500 lines is split by context into `<Suite>.<Context>.Tests.ps1`, keeping the contexts the ACs name in the AC-named file.
- Test isolation: imported `Docs*` modules and `Test-Json` mocks leak between suites, and an import proof based on `Get-Module` would be order-dependent. Prevented by `AfterAll` module removal in every suite, the static import graph in [P4-T6], in-memory contexts, the seeded shuffled file-order runs of the touched Pester suites with three seeds (1021, 20261030, 7), each seed and order recorded ([P6-T5]), and the fresh single-process run over `tests/scripts` ([P6-T6]). The seeded Jest shuffle and the reversed-order Python run are not applicable: the plan adds or changes no TypeScript and no Python test module.

- The plan has 43 tasks, above the 40-task guideline, and stays under 400 lines.
